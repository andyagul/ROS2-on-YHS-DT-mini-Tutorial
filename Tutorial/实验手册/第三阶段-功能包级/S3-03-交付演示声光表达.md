# S3-03 交付演示与夜间作业的声光表达

> 场景来源：[二次开发场景实施方案.md](../../二次开发场景实施方案.md) S3-03；清单条目：[二次开发项目清单.md](../../二次开发项目清单.md) 第三阶段 #3。
> 本实验新建 C++ 功能包 `yhs_indicator`：把导航状态（待机/规划中/行驶/恢复/故障）映射为转向灯、刹车灯、雾灯、近光、示廓灯与喇叭组合灯效，发布 `yhs_can_interfaces/msg/IoCmd` 到 `/io_cmd`。
> 约定：下文 `WS="$HOME/ros2_ws"`。

## 1. 实验信息

| 项目 | 内容 |
|---|---|
| 实验编号 | S3-03 |
| 实验阶段 | 第三阶段：完整功能包开发（建议 150 min / 3~4 学时） |

## 2. 实验目标

1. 能说明 `IoCmd` 中 `io_cmd_lamp_ctrl`、`io_cmd_lower_beam_headlamp`、`io_cmd_turn_lamp`（0 关/1 左/2 右）、`io_cmd_braking_lamp`、`io_cmd_fog_lamp`、`io_cmd_clearance_lamp`、`io_cmd_speaker` 的语义与驱动位含义。
2. 能把 `GoalStatusArray`（ACCEPTED/EXECUTING/CANCELING/ABORTED）与 `/cmd_vel` 角速度、`/chassis_info_fb` 故障位组合成 5 个作业状态。
3. 能实现"故障 > 恢复 > 行驶 > 规划 > 待机"的优先级与去抖，高优先级可抢占低优先级灯效。
4. 能把闪烁频率、保持时长、喇叭开关全部放入 YAML，并实现运行中一键静音（参数热更新立即生效）。
5. 能逐态核对 5 套灯效、实测夜间 30 m 可辨识，并证明喇叭单次 ≤ 1 s、灯效不干扰刹车灯语义。

### 6.3 `src/indicator_node.cpp`

```cpp
#include <algorithm>
#include <chrono>
#include <cmath>
#include <memory>
#include <string>

#include "action_msgs/msg/goal_status.hpp"
#include "action_msgs/msg/goal_status_array.hpp"
#include "geometry_msgs/msg/twist.hpp"
#include "rclcpp/rclcpp.hpp"
#include "yhs_can_interfaces/msg/chassis_info_fb.hpp"
#include "yhs_can_interfaces/msg/io_cmd.hpp"

using IoCmd = yhs_can_interfaces::msg::IoCmd;
using ChassisInfoFb = yhs_can_interfaces::msg::ChassisInfoFb;
using GoalStatusArray = action_msgs::msg::GoalStatusArray;
using GoalStatus = action_msgs::msg::GoalStatus;
using Clock = std::chrono::steady_clock;

class IndicatorNode : public rclcpp::Node
{
public:
  IndicatorNode() : Node("yhs_indicator")
  {
    declare_parameter("cmd_vel_topic", "/cmd_vel");
    declare_parameter("status_topic", "/navigate_to_pose/_action/status");
    declare_parameter("chassis_topic", "/chassis_info_fb");
    declare_parameter("io_topic", "/io_cmd");
    declare_parameter("publish_rate", 10.0);
    declare_parameter("angular_threshold", 0.1);
    declare_parameter("turn_hold", 0.5);
    declare_parameter("brake_decel", 0.03);
    declare_parameter("brake_hold", 1.0);
    declare_parameter("fault_hold", 3.0);
    declare_parameter("recovery_hold", 3.0);
    declare_parameter("beep_duration", 0.5);
    declare_parameter("beep_cooldown", 5.0);
    declare_parameter("speaker_enable", true);

    rate_ = get_parameter("publish_rate").as_double();
    ang_thr_ = get_parameter("angular_threshold").as_double();
    turn_hold_ = get_parameter("turn_hold").as_double();
    brake_decel_ = get_parameter("brake_decel").as_double();
    brake_hold_ = get_parameter("brake_hold").as_double();
    fault_hold_ = get_parameter("fault_hold").as_double();
    recov_hold_ = get_parameter("recovery_hold").as_double();
    beep_dur_ = get_parameter("beep_duration").as_double();
    beep_cool_ = get_parameter("beep_cooldown").as_double();

    io_pub_ = create_publisher<IoCmd>(get_parameter("io_topic").as_string(), 10);
    cmd_sub_ = create_subscription<geometry_msgs::msg::Twist>(
      get_parameter("cmd_vel_topic").as_string(), rclcpp::QoS(1),
      [this](const geometry_msgs::msg::Twist::SharedPtr m) {on_cmd(m);});
    status_sub_ = create_subscription<GoalStatusArray>(
      get_parameter("status_topic").as_string(), rclcpp::QoS(10),
      [this](const GoalStatusArray::SharedPtr m) {on_status(m);});
    chassis_sub_ = create_subscription<ChassisInfoFb>(
      get_parameter("chassis_topic").as_string(), rclcpp::QoS(1).reliable(),
      [this](const ChassisInfoFb::SharedPtr m) {on_chassis(m);});
    timer_ = create_wall_timer(
      std::chrono::milliseconds(static_cast<int>(1000.0 / rate_)), [this]() {tick();});
    start_ = Clock::now();
    RCLCPP_INFO(get_logger(), "声光表达已启动：5 态灯效，喇叭=%s，状态源 %s + %s",
      get_parameter("speaker_enable").as_bool() ? "开" : "静音",
      get_parameter("status_topic").as_string().c_str(),
      get_parameter("cmd_vel_topic").as_string().c_str());
  }

private:
  enum class Mode {IDLE, PLANNING, DRIVING, RECOVERY, FAULT};

  static const char * mname(Mode m)
  {
    switch (m) {
      case Mode::IDLE: return "IDLE(待机/到点)";
      case Mode::PLANNING: return "PLANNING(规划中)";
      case Mode::DRIVING: return "DRIVING(行驶)";
      case Mode::RECOVERY: return "RECOVERY(恢复)";
      default: return "FAULT(故障)";
    }
  }

  static Clock::duration sec(double s)
  {
    return std::chrono::duration_cast<Clock::duration>(std::chrono::duration<double>(s));
  }

  bool blink(double hz, const Clock::time_point & now) const
  {
    const double t = std::chrono::duration<double>(now - start_).count();
    return std::fmod(t, 1.0 / hz) < 0.5 / hz;
  }

  void on_cmd(const geometry_msgs::msg::Twist::SharedPtr m)
  {
    const auto now = Clock::now();
    const double v = m->linear.x, w = m->angular.z;
    if (w > ang_thr_) {turn_ = 1; turn_time_ = now;}
    else if (w < -ang_thr_) {turn_ = 2; turn_time_ = now;}
    else if (turn_ != 0 && now - turn_time_ > sec(turn_hold_)) {turn_ = 0;}
    if (have_last_ && last_v_ - v >= brake_decel_ && last_v_ > 0.02) brake_until_ = now + sec(brake_hold_);
    last_v_ = v; have_last_ = true;
  }

  void on_status(const GoalStatusArray::SharedPtr m)
  {
    const auto now = Clock::now();
    bool planning = false, executing = false, abnormal = false;
    for (const auto & s : m->status_list) {
      if (s.status == GoalStatus::STATUS_ACCEPTED) planning = true;
      if (s.status == GoalStatus::STATUS_EXECUTING) executing = true;
      if (s.status == GoalStatus::STATUS_CANCELING || s.status == GoalStatus::STATUS_ABORTED) abnormal = true;
    }
    planning_ = planning; executing_ = executing; last_status_ = now;
    if (abnormal) recovery_until_ = now + sec(recov_hold_);
  }

  void on_chassis(const ChassisInfoFb::SharedPtr m)
  {
    const auto & io = m->io_fb;
    const bool hit = io.io_fb_fl_impact_sensor || io.io_fb_fm_impact_sensor ||
      io.io_fb_fr_impact_sensor || io.io_fb_estop;
    if (!hit) return;
    const auto now = Clock::now();
    fault_until_ = now + sec(fault_hold_);
    if (get_parameter("speaker_enable").as_bool() && now >= next_beep_) {
      beep_until_ = now + sec(std::min(beep_dur_, 1.0));   // 喇叭单次 ≤ 1 s
      next_beep_ = now + sec(beep_cool_);
    }
  }

  Mode mode() const
  {
    const auto now = Clock::now();
    if (now < fault_until_) return Mode::FAULT;
    if (now < recovery_until_) return Mode::RECOVERY;
    if (executing_ && now - last_status_ < sec(1.0)) return Mode::DRIVING;
    if (planning_ && now - last_status_ < sec(1.0)) return Mode::PLANNING;
    return Mode::IDLE;
  }

  void tick()
  {
    const auto now = Clock::now();
    const Mode m = mode();
    const bool fast = blink(2.0, now);    // 2 Hz：故障/双闪
    const bool slow = blink(1.0, now);    // 1 Hz：规划/恢复
    IoCmd msg;
    msg.io_cmd_lamp_ctrl = true;              // 灯控使能，必须为 true
    msg.io_cmd_lower_beam_headlamp = true;    // 夜间近光常亮
    msg.io_cmd_clearance_lamp = true;         // 示廓灯常亮
    switch (m) {
      case Mode::FAULT:
        msg.io_cmd_braking_lamp = true;                  // 刹车灯常亮＝确认停车
        msg.io_cmd_fog_lamp = fast;                      // 雾灯闪
        msg.io_cmd_turn_lamp = fast ? 1 : 2;             // 无 hazard 字段，用左右交替表达双闪
        break;
      case Mode::RECOVERY:
        msg.io_cmd_fog_lamp = slow;
        msg.io_cmd_turn_lamp = slow ? 1 : 2;
        break;
      case Mode::DRIVING:
        msg.io_cmd_turn_lamp = static_cast<uint8_t>(turn_);
        msg.io_cmd_braking_lamp = now < brake_until_;
        break;
      case Mode::PLANNING:
        msg.io_cmd_turn_lamp = slow ? 1 : 2;
        break;
      default:                                          // IDLE：到点熄灯
        break;
    }
    msg.io_cmd_speaker = get_parameter("speaker_enable").as_bool() && now < beep_until_;
    io_pub_->publish(msg);
    if (!last_mode_told_ || m != last_mode_) {
      RCLCPP_INFO(get_logger(), "状态 → %s（转向=%d 刹车=%d 雾灯=%d 喇叭=%d）",
        mname(m), msg.io_cmd_turn_lamp, msg.io_cmd_braking_lamp,
        msg.io_cmd_fog_lamp, msg.io_cmd_speaker);
      last_mode_ = m; last_mode_told_ = true;
    }
  }

  rclcpp::Publisher<IoCmd>::SharedPtr io_pub_;
  rclcpp::Subscription<geometry_msgs::msg::Twist>::SharedPtr cmd_sub_;
  rclcpp::Subscription<GoalStatusArray>::SharedPtr status_sub_;
  rclcpp::Subscription<ChassisInfoFb>::SharedPtr chassis_sub_;
  rclcpp::TimerBase::SharedPtr timer_;
  Clock::time_point start_, last_status_{}, turn_time_{}, brake_until_{}, fault_until_{};
  Clock::time_point recovery_until_{}, beep_until_{}, next_beep_{};
  Mode last_mode_{Mode::IDLE};
  bool last_mode_told_{false}, have_last_{false}, planning_{false}, executing_{false};
  double last_v_{0.0};
  int turn_{0};
  double rate_{10.0}, ang_thr_{0.1}, turn_hold_{0.5}, brake_decel_{0.03}, brake_hold_{1.0};
  double fault_hold_{3.0}, recov_hold_{3.0}, beep_dur_{0.5}, beep_cool_{5.0};
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<IndicatorNode>());
  rclcpp::shutdown();
  return 0;
}
```

### 6.4 `config/indicator.yaml`

```yaml
yhs_indicator:
  ros__parameters:
    cmd_vel_topic: "/cmd_vel"
    status_topic: "/navigate_to_pose/_action/status"

    recovery_hold: 3.0          # 恢复灯效保持时长（s）
    beep_duration: 0.5          # 喇叭单次鸣叫（s，代码内上限 1 s）

    speaker_enable: true        # 一键静音开关，运行中可 set 参数
```

终端 A 预期：`声光表达已启动：5 态灯效，喇叭=开，状态源 /fake_status + /cmd_vel`；`ros2 topic info /io_cmd -v` 出现发布者 `yhs_indicator`。

| 目标状态 | 注入命令（终端 B） | 预期 `/io_cmd`（终端 C：`ros2 topic echo /io_cmd`） |
|---|---|---|
| IDLE | 不发布任何消息 5 s | `turn_lamp: 0`、`braking_lamp: false`、`fog_lamp: false`（近光/示廓灯 true） |
| PLANNING | `ros2 topic pub -r 2 /fake_status action_msgs/msg/GoalStatusArray "{status_list: [{status: 1}]}"` | `turn_lamp` 以 1 Hz 在 `1`/`2` 间交替 |
| DRIVING | `ros2 topic pub -r 2 /fake_status ... "{status_list: [{status: 2}]}"` + `ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2}, angular: {z: 0.2}}"` | `turn_lamp: 1`（左）；`angular.z: -0.2` 时为 `2` |
| 刹车 | 把上条改为 `"{linear: {x: 0.0}}"` | `braking_lamp: true` 保持约 1 s 后转 false |
| RECOVERY | `ros2 topic pub -r 2 /fake_status ... "{status_list: [{status: 6}]}"` | `fog_lamp` 1 Hz 闪、`turn_lamp` 1 Hz 交替、刹车灯灭 |
| FAULT | `ros2 topic pub -r 10 /chassis_info_fb yhs_can_interfaces/msg/ChassisInfoFb "{io_fb: {io_fb_fl_impact_sensor: true}}"` | `braking_lamp: true` 常亮、`fog_lamp` 2 Hz 闪、`speaker` 每 5 s 短鸣 ≤ 1 s |

终端 A 日志预期：

```text
[INFO] [yhs_indicator]: 状态 → DRIVING(行驶)（转向=1 刹车=0 雾灯=0 喇叭=0）
[INFO] [yhs_indicator]: 状态 → FAULT(故障)（转向=1 刹车=1 雾灯=1 喇叭=1）
```

一键静音与恢复：

```bash
ros2 param set /yhs_indicator speaker_enable false    # 立即生效，下个周期起 speaker 恒为 false
ros2 param set /yhs_indicator speaker_enable true
```

优先级验证：保持 FAULT 注入的同时发 `/fake_status` 的 `status: 2` 与 0.2 m/s 速度，`io_cmd` 必须持续为故障灯效（刹车常亮 + 雾灯闪），故障保持 3 s 结束后才回 DRIVING。

夜间 30 m 可辨识：遮光走廊中，车辆静止置于一端，测试员在 30 m 处逐态判断"待机/规划/行驶/恢复/故障"，5 态全部可辨认即通过；同时记录喇叭声压可闻距离。

判定标准：5 态灯效与上表逐项一致；FAULT 抢占生效；静音后无喇叭；`/io_cmd` 记录中 `braking_lamp` 只在减速/停车/故障时为 true（不干扰制动语义）。

## 9. 验收指标

| 维度 | 量化要求 | 判定方法 |
|---|---|---|
| 功能完整性 | 5 态灯效 100% 正确；静音开关有效 | 8 节六行注入逐项核对，录像留档 |

| 稳定性 | 连续 4 h 演示无灯态卡死；重启后回默认 IDLE | 4 h 挂机 + 3 次重启复测 |
| 可辨识度 | 夜间 30 m 可辨识 5 态；转向灯提前 ≥ 0.5 s | 现场实测记录 + `/cmd_vel` 时间戳比对 |

## 10. 回滚与常见问题

```bash
# 1) Ctrl+C 停灯效节点（退出前最后一条 IoCmd 已把灯光置默认态）
ros2 topic pub -r 5 --times 5 /io_cmd yhs_can_interfaces/msg/IoCmd "{io_cmd_lamp_ctrl: true}"   # 兜底全灭
rm -rf "$WS"/build/yhs_indicator "$WS"/install/yhs_indicator
rm -rf "$WS"/src/yhs_indicator
source "$WS"/install/setup.bash && ros2 pkg list | grep yhs_indicator    # 应无输出
git -C "$WS" status --short                                              # 应无残留
```

| 现象 | 原因 | 处理 |
|---|---|---|
| 灯全不亮 | `io_cmd_lamp_ctrl` 为 false，或灯光电源/保险断开 | 用 `ros2 topic pub` 手发 `lamp_ctrl: true` 验证；查保险 |
| 只有喇叭响、灯不亮 | 近光/示廓灯未供电，驱动只透传了 speaker 位 | 查灯控线束；`ip link` 与 CAN 无关 |
| 左右转向灯相反 | 灯线接反或车体定义不同 | 用 `angular.z=+0.2` 对照实车；接反交维修 |
| 状态在 IDLE/PLANNING 间跳 | `status_list` 含历史目标（旧 ABORTED 触发恢复） | 只保留最新目标；必要时提高 `recovery_hold` |
| 与 S2-04 脚本抢占 | 两个节点同时发 `/io_cmd` | `ros2 topic info /io_cmd -v` 只留一个发布者 |
| `param set speaker_enable` 无效 | 节点名不是 `yhs_indicator`（被 launch 改名） | `ros2 node list` 确认实际节点名 |
| `/io_cmd` 无订阅者 | 底盘节点未启动 | `ros2 launch yhs_can_control yhs_can_control.launch.py` |
| 编译报 `action_msgs` 缺失 | 依赖未写全 | 确认 6.1 有 `<depend>action_msgs</depend>`，`sudo apt install ros-humble-action-msgs` |
