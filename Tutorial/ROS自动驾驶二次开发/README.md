# 二次开发实验手册

本目录把 [二次开发项目清单](二次开发项目清单.md) 中的 33 个功能项，逐一展开为可复现的独立实验文档；每个实验的场景背景与验收口径来自 [二次开发场景实施方案](二次开发场景实施方案.md)。



## 一、目录结构

```
Tutorial/实验手册/
├── README.md                 # 本文件：索引与统一约定
├── 第一阶段-参数级/           # S1-01 ~ S1-16（16 个，仅改参数，零代码）
├── 第二阶段-脚本级/           # S2-01 ~ S2-10（10 个，单文件 rclpy 脚本）
└── 第三阶段-功能包级/         # S3-01 ~ S3-07（7 个，完整 ROS 2 功能包）
```

## 二、统一约定（所有实验通用）

| 项目 | 约定 |
|---|---|
| 工作空间变量 | `export WS="$HOME/ros2_ws"`（即 `~/ros2_ws`） |
| 命令中的 `cd "$WS"` | 等价于 `cd ~/ros2_ws`，`$WS` 由上一条 `export` 提供；每打开新终端都需重新执行一次 |
| 环境初始化 | 每个新终端执行 `source /opt/ros/humble/setup.bash && source "$WS/install/setup.bash"` |
| 实验产物目录 | 第一阶段、第二阶段统一放在 `$HOME/yhs_labs/<实验编号>/`（`backup/`、`result/`），**不写入 `src/`** |
| 第三阶段代码位置 | 必须在 `$WS/src/<包名>/` 下建包，才能被 `colcon` 发现 |
| 参数改动 | 改前用 `cp -a` 备份并记录 `sha256sum`；改后用 `ros2 param get` 回读确认 |
| 编译命令 | 第三阶段：`cd "$WS" && colcon build --symlink-install --packages-select <包名>`；第一、二阶段文档中已注明是否需要重新编译 |
| 安全底线 | 架空车轮验证优先；首次落地限速 0.2 m/s；安全员持硬件急停全程随行 |
| 运行区域 | 仅园区、库区、变电站内部非公开道路，不进入市政道路 |

## 六、每个文档的固定结构

1. 实验信息（编号、阶段、对应清单条目、时长、前置实验、硬件与场地）
2. 实验目标（可检验）
3. 前置条件与开机检查（命令 + 预期输出）
4. 目录与文件准备（执行目录、新建目录命令、文件完整路径、备份）
5. 实施步骤（操作 → 命令/代码 → 预期输出 → 完成标志）
6. 关键代码与配置（完整片段、插入位置、原值 → 新值）
7. 编译与环境刷新（执行目录、完整命令、参数说明、预期输出）
8. 运行验证（多终端分工、启动顺序、判定标准）
9. 验收指标（功能完整性 / 安全性 / 稳定性，量化）
10. 回滚与常见问题（具体报错与处理）
