## 2. 实验目标

1. 说明 `select_car.sh` 失败的直接原因：7 条 `cp` 命令全部硬编码 `/home/yhs/ros2_ws/src/yhs_chassis_description/launch/...`，与现场工作空间不一致。
2. 列出并正确启动全部 **7 个车型 launch**：`DT-mid`、`DT-mini`、`FR-mid`、`FR-mini`、`FW-mid`、`MK-mid`、`TK-mid`。
3. 用"改脚本"和"直接指定车型 launch"两种做法完成切换，单车型切换 ≤ 5 min，且不产生错误的 `robot.launch.py` 覆盖。
4. 发现并处理仓库中 2 处真实缺陷：`select_car.sh` 的 D 分支（FR-mini）实际拷贝 `DT-mini.launch.py`；`FR-mid.launch.py` 默认 URDF 指向 `DT-mini.urdf`。
5. 用 `tf2_echo` 与实测尺寸核对：模型与实车尺寸偏差 ≤ 10 mm，`base_link→laser_link` 平移为 `0.000 / 0.000 / 0.330`。

## 6. 关键配置与代码

### 6.1 做法 A：`src/tools/select_car.sh` 修正后完整脚本

**位置**：替换原第 1~64 行（`#!/bin/bash` 到 `esac`）。
**原值 → 新值**：7 条 `cp /home/yhs/ros2_ws/...` → `cp "$DESC/..."`；D 分支源文件 `DT-mini.launch.py` → `FR-mini.launch.py`。

```bash
#!/bin/bash
# 以脚本自身位置推算工程路径，避免硬编码 /home/yhs/ros2_ws
DESC="$(cd "$(dirname "${BASH_SOURCE[0]}")/../yhs_chassis_description/launch" && pwd)"
echo "请选择一个车型："
echo "A: DT-mid / B: DT-mini / C: FR-mid / D: FR-mini / E: FW-mid / F: MK-mid / G: TK-mid"
read -p "输入选项，大小写均可: " option
case "$option" in
    A|a) F=DT-mid ;; B|b) F=DT-mini ;; C|c) F=FR-mid ;; D|d) F=FR-mini ;;
    E|e) F=FW-mid ;; F|f) F=MK-mid ;; G|g) F=TK-mid ;;
    *) echo "错误：无效选项，请选择 A、B、C、D、E、F 或 G."; exit 1 ;;
esac

SRC="$DESC/$F.launch.py"
[ -f "$SRC" ] || { echo "错误：找不到 $SRC"; exit 1; }
cp "$SRC" "$DESC/robot.launch.py" && echo "已切换为 $F"
```

| 改动点 | 原值 | 新值 | 含义 |
|---|---|---|---|
| 路径 | `/home/yhs/ros2_ws/src/yhs_chassis_description/launch` | `DESC`（由脚本位置推导） | 脚本随仓库整体搬移，无需再改 |
| D 分支 | `cp .../DT-mini.launch.py .../robot.launch.py` | `cp "$DESC/FR-mini.launch.py" ...` | 修正"选 FR-mini 却加载 DT-mini"的真实缺陷 |
| 校验 | 无 | `[ ! -f "$SRC" ]` | 路径错时给明确错误，而非静默 `cp` 失败 |

### 6.2 做法 B：车型 launch 与 URDF 的真实对应关系

| 车型 | launch 文件（`src/yhs_chassis_description/launch/`） | 默认 URDF | 是否需要 `urdf_model:=` |
|---|---|---|---|
| DT-mini | `DT-mini.launch.py` | `DT-mini.urdf` | 否 |
| DT-mid | `DT-mid.launch.py` | `DT-mid.urdf` | 否 |
| FR-mid | `FR-mid.launch.py` | `DT-mini.urdf`（缺陷） | **是**，传 `FR_mid.urdf` |
| FR-mini | `FR-mini.launch.py` | `FR-mini.urdf`（文件不存在） | **是**，传 `FR_mini.urdf` |
| FW-mid | `FW-mid.launch.py` | `FW-mid.urdf` | 否 |
| MK-mid | `MK-mid.launch.py` | `MK-mid.urdf` | 否 |
| TK-mid | `TK-mid.launch.py` | `TK-mid.urdf` | 否 |

可选修正（`src/yhs_chassis_description/launch/FR-mid.launch.py` 第 21 行）：把 `default_value=os.path.join(pkg_dir, 'urdf', 'DT-mini.urdf')` 中的 `'DT-mini.urdf'` 改为 `'FR_mid.urdf'`。

### 6.3 交付时必须知道的三个事实

1. 每个 `*.urdf` 只有 `base_link` 一个 link，且只有 visual（mesh），**没有 joint、没有 laser_link/imu_link**；"模型与实车一致"只能核对外观包络，外参必须去雷达/IMU 的 launch 看。
2. `robot.launch.py` 与 `DT-mini.launch.py` 内容相同（默认 URDF 均为 `DT-mini.urdf`）；做法 A 的本质就是用目标车型 launch 覆盖 `robot.launch.py`。
3. `use_robot_state_pub` 参数**已声明但未绑定 condition**，传 `use_robot_state_pub:=false` 不会停掉 `robot_state_publisher`，只能 `Ctrl+C` 或改文件。
