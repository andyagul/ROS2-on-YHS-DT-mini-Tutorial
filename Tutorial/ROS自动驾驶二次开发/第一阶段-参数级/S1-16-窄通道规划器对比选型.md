## 2. 实验目标

1. 能确认 `nav2_smac_planner/SmacPlanner2D` 在本工作空间**真实存在**（源码包 + 插件 XML + 可解析路径）。
2. 仅通过 `planner_plugins.GridBased.plugin` 在两套全局规划器间切换，控制器（TEB）保持不变。
3. 对 5 个代表性目标点各采集 ≥ 5 次，记录路径点数、路径长度、`planning_time`、最小间距、成功率。
4. 形成量化选型结论：窄通道用哪种、开阔区用哪种，并给出推荐参数。
5. 选定配置回归 5 个用例全部可达，最小间距 ≥ 0.15 m。

### 步骤 1：选定 5 个代表性用例（20 min）

| 用例 | 起点 | 终点 | 场景特征 |
|---|---|---|---|
| C1 | 通道口 (0, 0) | 窄通道中部 | 净宽 0.9 m，两侧货架 |
| C2 | 窄通道中部 | 通道另一端 | 需贴边通过，无倒车 |
| C3 | 开阔区西侧 | 开阔区东侧 | 长直线 4 m，无障碍 |
| C4 | 开阔区 | 货架死角 | 需绕行 + 末段贴边 |
| C5 | 通道口 | 死角后方点位 | 需绕障且末段窄通道 |

### 步骤 3：采集 NavFn 数据（30 min）

单次规划（只算路径、不驱车，安全可重复）：

```bash
# 终端 T2，执行目录：任意
ros2 action send_goal /compute_path_to_pose nav2_msgs/action/ComputePathToPose \
  "{goal: {header: {frame_id: 'map'}, pose: {position: {x: 2.0, y: 0.0, z: 0.0}, orientation: {w: 1.0}}},
    use_start: false, planner_id: 'GridBased'}"
```

预期输出示例（`planning_time` 即规划耗时，以下约 31 ms）：

```
Result:
  path: {header: {frame_id: map}, poses: [...]}
  planning_time: {sec: 0, nanosec: 31245871}
```

路径点数与长度用只读采集脚本取回（不新建源码文件、不参与编译）：

```bash
# 终端 T3，执行目录：任意
python3 - <<'EOF'
import rclpy, math
from rclpy.node import Node
from nav_msgs.msg import Path
class M(Node):
    def __init__(self):
        super().__init__('plan_metrics'); self.msg = None
        self.create_subscription(Path, '/plan', self.cb, 1)
    def cb(self, m):
        self.msg = m
rclpy.init(); n = M()
while n.msg is None:
    rclpy.spin_once(n, timeout_sec=0.5)
p = n.msg.poses
L = sum(math.hypot(b.pose.position.x - a.pose.position.x, b.pose.position.y - a.pose.position.y) for a, b in zip(p[:-1], p[1:]))
print(f"points={len(p)} length={L:.2f} m")
rclpy.shutdown()
EOF
```

预期输出示例：`points=48 length=3.42 m`。

最小间距：RViz2 同时勾选 `Global Costmap` 与 `Path`，用 `Measure` 工具量路径到障碍边缘的最小距离；静态场景也可用卷尺量停车位置到货架的距离。
判定标准（基线）：C1/C2 能规划但贴边（常 < 0.15 m），C3/C4 平顺，C5 偶发失败。

## 6. 关键配置与代码

### 6.1 `yhs_nav2.yaml` 的 `planner_server` 段：原值 → 新值

文件：`~/ros2_ws/src/yhs_nav2/param/yhs_nav2.yaml`，插入位置：第 348–357 行（整段替换）。

原值（NavFn 基线）：

```yaml
planner_server:
  ros__parameters:
    expected_planner_frequency: 20.0 #TODO
    use_sim_time: False
    planner_plugins: ["GridBased"]
    GridBased:
      plugin: "nav2_navfn_planner/NavfnPlanner" #TODO
      tolerance: 0.5
      use_astar: true #TODO
      allow_unknown: false
```

新值（SmacPlanner2D 档）：

```yaml
planner_server:
  ros__parameters:
    expected_planner_frequency: 20.0
    use_sim_time: False
    planner_plugins: ["GridBased"]
    GridBased:
      plugin: "nav2_smac_planner/SmacPlanner2D"
      tolerance: 0.5
      allow_unknown: false
      downsample_costmap: false
      downsampling_factor: 1
      max_iterations: 1000000
      max_on_approach_iterations: 1000
      max_planning_time: 2.0
      cost_travel_multiplier: 2.0
      use_final_approach_orientation: false
```

参数含义（均可在 `src/navigation2/nav2_smac_planner/src/smac_planner_2d.cpp` 第 64–92 行找到同名 `declare_parameter_if_not_declared`）：

| 参数 | 取值 | 含义 |
|---|---|---|
| `plugin` | `nav2_smac_planner/SmacPlanner2D` | 2D A\* 网格规划器插件类名（`smac_plugin_2d.xml` 第 2 行） |
| `tolerance` / `allow_unknown` | 0.5 / false | 目标容差与 NavFn 同口径；不穿越未知栅格，窄通道安全优先 |
| `downsample_costmap` / `downsampling_factor` | false / 1 | 不降采样，保留 5 cm 分辨率，防窄通道误判 |
| `max_iterations` / `max_on_approach_iterations` | 1000000 / 1000 | 搜索迭代上限，防死角长时间卡死 |
| `max_planning_time` | 2.0 | 单次规划时间上限（s） |
| `cost_travel_multiplier` | 2.0 | 代价乘子，越大越远离高代价区（贴边更保守） |
| `use_final_approach_orientation` | false | 末段不强求目标朝向，减少终点原地调整 |

控制器段（`controller_server.FollowPath.plugin: teb_local_planner::TebLocalPlannerROS`）**不改**，保证变量唯一，差异才能归因到路径形态。

## 10. 回滚与常见问题

```bash
# 回滚，执行目录：工作空间根
cp ~/yhs_labs/S1-16/backup/yhs_nav2.yaml.bak src/yhs_nav2/param/yhs_nav2.yaml
colcon build --symlink-install --packages-select yhs_nav2 && source install/setup.bash
ros2 param get /planner_server GridBased.plugin     # 回到 nav2_navfn_planner/NavfnPlanner
```

| 现象 / 报错 | 原因 | 处理 |
|---|---|---|
| `Failed to create planner GridBased of type nav2_smac_planner/SmacPlanner2D` | 插件未安装/未编译，或类名写错 | 回第 3 节三项核对；类名大小写敏感，注意 `2D` 不是 `2d` |
| `Failed to create a unique pose path because of obstacles` | `allow_unknown: false` 且目标落在未知区；或膨胀层封死通道 | 先把 `allow_unknown` 设 `true` 试探；窄通道需先完成 S1-03 的 `inflation_radius` 0.55 |
| 规划成功但车在路上反复修正 | TEB 参数不适配新路径形态 | 本实验不改控制器，先记录现象；必要时按 S1-01 收敛 `max_vel_x`/`acc_lim_*` 后复测 |
| `planning_time` 波动 > ±20% | CPU 负载波动，或重复起栈导致多份 `planner_server` | `ros2 node list | grep planner_server` 确认只有一份；关掉 RViz 无关显示 |
| 切换后 `/plan` 形态不变 | 订阅了旧话题，或旧节点仍在运行 | `ros2 node list` 清残留；`ros2 topic info /plan` 确认发布者只有一个 |
