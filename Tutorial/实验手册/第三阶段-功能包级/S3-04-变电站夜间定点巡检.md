# S3-04 变电站夜间定点巡检任务

> 场景来源：[二次开发场景实施方案.md](../../二次开发场景实施方案.md) S3-04；清单条目：[二次开发项目清单.md](../../二次开发项目清单.md) 第三阶段 #4。
> 本实验新建 C++ 功能包 `yhs_patrol`：自定义 `PatrolRoute` action server，内部复用 Nav2 的 `NavigateToPose` action client，按路线 YAML 顺序到点、停留、循环、失败重试、断点续跑，并支持中途取消。
> 约定：下文 `WS="$HOME/ros2_ws"`。

## 2. 实验目标

1. 能定义一个自定义 action（goal/result/feedback 三段），并说明与本仓库已有 `nav2_msgs/action/NavigateToPose`、`yhs_can_interfaces/action/RecordPath` 的关系（复用导航能力，不重复实现路径跟踪）。
2. 能在同一 `ament_cmake` 包内同时生成 ROS 接口与编译 C++ 节点（`rosidl_generate_interfaces` + `rosidl_get_typesupport_target`）。
3. 能用 action client 在 action server 的 execute 线程中调用 `NavigateToPose`，处理 goal 响应、结果、反馈与取消。
4. 能用 yaml-cpp 解析路线文件（点位名、x、y、yaw、dwell），实现停留、失败重试、`start_index` 断点续跑、`loop/max_rounds` 循环。
5. 能实测 12 点单轮 ≤ 20 min、到位率 ≥ 98%，并验证中途取消与续跑。

### 6.4 `src/patrol_server_node.cpp`

```cpp
#include <algorithm>
#include <atomic>
#include <chrono>
#include <cmath>
#include <future>
#include <memory>
#include <string>
#include <thread>
#include <vector>

#include "ament_index_cpp/get_package_share_directory.hpp"
#include "nav2_msgs/action/navigate_to_pose.hpp"
#include "rclcpp/rclcpp.hpp"
#include "rclcpp_action/rclcpp_action.hpp"
#include "yaml-cpp/yaml.h"
#include "yhs_patrol/action/patrol_route.hpp"

using namespace std::chrono_literals;
using PatrolRoute = yhs_patrol::action::PatrolRoute;
using GoalHandle = rclcpp_action::ServerGoalHandle<PatrolRoute>;
using NavigateToPose = nav2_msgs::action::NavigateToPose;
using NavGoalHandle = rclcpp_action::ClientGoalHandle<NavigateToPose>;

struct Waypoint
{
  std::string name;
  double x{0.0}, y{0.0}, yaw{0.0}, dwell{5.0};
};

class PatrolServer : public rclcpp::Node
{
public:
  PatrolServer() : Node("yhs_patrol_server")
  {
    declare_parameter("route_file", "");
    declare_parameter("frame_id", "map");
    declare_parameter("dwell_time", 5.0);
    declare_parameter("max_retries", 2);
    declare_parameter("retry_delay", 2.0);
    declare_parameter("navigate_action", "/navigate_to_pose");

    default_route_ = get_parameter("route_file").as_string();
    if (default_route_.empty()) {
      default_route_ = ament_index_cpp::get_package_share_directory("yhs_patrol") + "/config/line_a.yaml";
    }
    frame_id_ = get_parameter("frame_id").as_string();
    dwell_default_ = get_parameter("dwell_time").as_double();
    retries_ = static_cast<int>(get_parameter("max_retries").as_int());
    retry_delay_ = get_parameter("retry_delay").as_double();

    nav_client_ = rclcpp_action::create_client<NavigateToPose>(
      this, get_parameter("navigate_action").as_string());

    server_ = rclcpp_action::create_server<PatrolRoute>(
      this, "patrol",
      [this](const rclcpp_action::GoalUUID & uuid, std::shared_ptr<const PatrolRoute::Goal> goal) {
        return handle_goal(uuid, goal);
      },
      [this](const std::shared_ptr<GoalHandle> gh) {return handle_cancel(gh);},
      [this](const std::shared_ptr<GoalHandle> gh) {handle_accepted(gh);});
    RCLCPP_INFO(get_logger(), "巡检 action server 已启动：/patrol，默认路线 %s", default_route_.c_str());
  }

private:
  rclcpp_action::GoalResponse handle_goal(
    const rclcpp_action::GoalUUID &, std::shared_ptr<const PatrolRoute::Goal> goal)
  {
    if (goal->max_rounds == 0) {
      RCLCPP_WARN(get_logger(), "拒绝目标：max_rounds 必须 ≥ 1");
      return rclcpp_action::GoalResponse::REJECT;
    }
    if (busy_.load()) {
      RCLCPP_WARN(get_logger(), "拒绝目标：已有巡检任务在执行");
      return rclcpp_action::GoalResponse::REJECT;
    }
    return rclcpp_action::GoalResponse::ACCEPT_AND_EXECUTE;
  }

  rclcpp_action::CancelResponse handle_cancel(const std::shared_ptr<GoalHandle>)
  {
    RCLCPP_WARN(get_logger(), "收到取消请求，将在下一个 100 ms 检查点退出");
    return rclcpp_action::CancelResponse::ACCEPT;
  }

  void handle_accepted(const std::shared_ptr<GoalHandle> gh)
  {
    busy_.store(true);
    std::thread([this, gh]() {execute(gh);}).detach();   // execute 在自己的线程，避免阻塞执行器
  }

  bool load_route(const std::string & path, std::vector<Waypoint> & wps, std::string & err)
  {
    YAML::Node root;
    try {
      root = YAML::LoadFile(path);
    } catch (const std::exception & e) {
      err = e.what(); return false;
    }
    if (root["frame_id"]) frame_id_ = root["frame_id"].as<std::string>();
    const YAML::Node pts = root["points"];
    if (!pts || !pts.IsSequence()) {err = "points 字段缺失或不是列表"; return false;}
    for (const auto & p : pts) {
      try {
        Waypoint w;
        w.name = p["name"] ? p["name"].as<std::string>() : ("P" + std::to_string(wps.size() + 1));
        w.x = p["x"].as<double>(); w.y = p["y"].as<double>();
        w.yaw = p["yaw"] ? p["yaw"].as<double>() : 0.0;
        w.dwell = p["dwell"] ? p["dwell"].as<double>() : dwell_default_;
        wps.push_back(w);
      } catch (const std::exception & e) {
        err = std::string("点位解析失败：") + e.what(); return false;
      }
    }
    if (wps.empty()) {err = "路线为空"; return false;}
    return true;
  }

  void publish_feedback(const std::shared_ptr<GoalHandle> & gh, size_t idx, int round,
    size_t total, const std::string & name, float dist, const std::string & state)
  {
    auto fb = std::make_shared<PatrolRoute::Feedback>();
    fb->current_index = static_cast<uint16_t>(idx);
    fb->total_points = static_cast<uint16_t>(total);
    fb->current_round = static_cast<uint16_t>(round);
    fb->current_point_name = name;
    fb->state = state;
    fb->distance_remaining = dist;
    gh->publish_feedback(fb);
  }

  int navigate_once(const std::shared_ptr<GoalHandle> & gh, const Waypoint & wp,
    size_t idx, int round, size_t total)
  {
    NavigateToPose::Goal g;
    g.pose.header.frame_id = frame_id_;
    g.pose.header.stamp = now();
    g.pose.pose.position.x = wp.x;
    g.pose.pose.position.y = wp.y;
    g.pose.pose.orientation.z = std::sin(wp.yaw / 2.0);
    g.pose.pose.orientation.w = std::cos(wp.yaw / 2.0);

    auto opts = rclcpp_action::Client<NavigateToPose>::SendGoalOptions();
    opts.feedback_callback = [this, gh, idx, round, total, wp](
      NavGoalHandle::SharedPtr, const std::shared_ptr<const NavigateToPose::Feedback> fb) {
      publish_feedback(gh, idx, round, total, wp.name, fb->distance_remaining, "NAVIGATING");
    };
    auto goal_future = nav_client_->async_send_goal(g, opts);
    if (goal_future.wait_for(3s) != std::future_status::ready) return 1;
    auto nav_gh = goal_future.get();
    if (!nav_gh) return 1;

    auto result_future = nav_client_->async_get_result(nav_gh);
    while (result_future.wait_for(100ms) != std::future_status::ready) {
      if (gh->is_canceling()) {
        nav_client_->async_cancel_goal(nav_gh);
        return 2;
      }
    }
    return result_future.get().code == rclcpp_action::ResultCode::SUCCEEDED ? 0 : 1;
  }

  void execute(const std::shared_ptr<GoalHandle> gh)
  {
    auto goal = gh->get_goal();
    auto result = std::make_shared<PatrolRoute::Result>();
    const std::string path = goal->route_file.empty() ? default_route_ : goal->route_file;
    std::vector<Waypoint> wps; std::string err;
    if (path.empty() || !load_route(path, wps, err)) {
      result->success = false; result->message = "路线加载失败：" + err + "（" + path + "）";
      RCLCPP_ERROR(get_logger(), "%s", result->message.c_str());
      gh->abort(result); busy_.store(false); return;
    }
    if (!nav_client_->wait_for_action_server(5s)) {
      result->success = false; result->message = "Nav2 /navigate_to_pose 未就绪";
      RCLCPP_ERROR(get_logger(), "%s", result->message.c_str());
      gh->abort(result); busy_.store(false); return;
    }
    const size_t start = std::min<size_t>(goal->start_index, wps.size() - 1);
    const int rounds = goal->loop ? std::max<int>(1, goal->max_rounds) : 1;
    RCLCPP_INFO(get_logger(), "开始巡检：路线 %s，%zu 点，%d 轮，起点 %zu",
      path.c_str(), wps.size(), rounds, start);
    uint16_t completed = 0;
    for (int round = 1; round <= rounds; ++round) {
      for (size_t i = (round == 1 ? start : 0); i < wps.size(); ++i) {
        int code = 1;
        for (int attempt = 0; attempt <= retries_ && code != 0; ++attempt) {
          code = navigate_once(gh, wps[i], i, round, wps.size());
          if (code == 2) {
            result->message = "导航途中取消";
            gh->canceled(result); busy_.store(false); return;
          }
          if (code != 0 && attempt < retries_) {
            RCLCPP_WARN(get_logger(), "点位 %s 第 %d 次失败，%.1f s 后重试",
              wps[i].name.c_str(), attempt + 1, retry_delay_);
            for (double t = 0; t < retry_delay_ && !gh->is_canceling(); t += 0.1) {
              std::this_thread::sleep_for(100ms);
            }
          }
        }
        if (code != 0) {
          result->success = false;
          result->completed_points = completed;
          result->completed_rounds = static_cast<uint16_t>(round - 1);
          result->message = "点位 " + wps[i].name + " 连续失败，任务中止";
          RCLCPP_ERROR(get_logger(), "%s", result->message.c_str());
          gh->abort(result); busy_.store(false); return;
        }
        ++completed;
        const double dwell = goal->dwell_time > 0.0f ? goal->dwell_time : wps[i].dwell;
        for (double t = 0; t < dwell; t += 0.1) {
          if (gh->is_canceling()) {
            result->message = "停留途中取消";
            gh->canceled(result); busy_.store(false); return;
          }
          publish_feedback(gh, i, round, wps.size(), wps[i].name, 0.0f, "DWELL");
          std::this_thread::sleep_for(100ms);
        }
        RCLCPP_INFO(get_logger(), "第 %d 轮 点位 %s 完成（累计 %d）",
          round, wps[i].name.c_str(), static_cast<int>(completed));
      }
    }
    result->success = true;
    result->completed_points = completed;
    result->completed_rounds = static_cast<uint16_t>(rounds);
    result->message = "巡检完成";
    RCLCPP_INFO(get_logger(), "巡检完成：%d 点 × %d 轮",
      static_cast<int>(completed), rounds);
    gh->succeed(result);
    busy_.store(false);
  }

  rclcpp_action::Server<PatrolRoute>::SharedPtr server_;
  rclcpp_action::Client<NavigateToPose>::SharedPtr nav_client_;
  std::atomic<bool> busy_{false};
  std::string default_route_, frame_id_{"map"};
  double dwell_default_{5.0}, retry_delay_{2.0};
  int retries_{2};
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<PatrolServer>());
  rclcpp::shutdown();
  return 0;
}
```

### 6.7 `launch/patrol.launch.py`

```python
import os

from ament_index_python.packages import get_package_share_directory
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node


def generate_launch_description():
    share = get_package_share_directory('yhs_patrol')
    route_file = LaunchConfiguration('route_file')
    dwell_time = LaunchConfiguration('dwell_time')

    return LaunchDescription([
        DeclareLaunchArgument(
            'route_file', default_value=os.path.join(share, 'config', 'line_a.yaml'),
            description='巡检路线 YAML（A/B 线切换）'),
        DeclareLaunchArgument(
            'dwell_time', default_value='0.0',
            description='覆盖每点停留秒数，0 表示用 YAML 的 dwell'),
        Node(
            package='yhs_patrol',
            executable='yhs_patrol_server_node',
            name='yhs_patrol_server',
            output='screen',
            parameters=[{
                'route_file': route_file,
                'frame_id': 'map',
                'dwell_time': dwell_time,
                'max_retries': 2,
                'retry_delay': 2.0,
                'navigate_action': '/navigate_to_pose',
            }],
        ),
    ])
```

## 10. 回滚与常见问题

```bash
# 1) Ctrl+C 停 B 终端；确认车辆停止（必要时按急停）
rm -rf "$WS"/build/yhs_patrol "$WS"/install/yhs_patrol
rm -rf "$WS"/src/yhs_patrol
source "$WS"/install/setup.bash && ros2 pkg list | grep yhs_patrol    # 应无输出
git -C "$WS" status --short                                          # 应无残留
```

| 现象 | 原因 | 处理 |
|---|---|---|
| `rosidl_generate_interfaces` 报找不到 action | `action/PatrolRoute.action` 不在 `action/` 目录或三段 `---` 缺失 | 按 6.3 原文重写，确认两行 `---` |
| 链接报 `undefined reference to yhs_patrol::action::...` | 少了 `rosidl_get_typesupport_target` + `target_link_libraries` | 按 6.2 补两行后重新 `colcon build` |
| `ros2 action send_goal` 报类型未知 | 未 source `install/setup.bash` | 重新 source；`ros2 interface list \| grep yhs_patrol` 验证 |
| 报 `package 'yhs_patrol' is not a member of rosidl_interface_packages` | `package.xml` 缺 `member_of_group` | 补 6.1 中该行 |
| 启动即 `路线加载失败` | 路径不存在、`points` 写成映射而非列表、`x/y` 缺失 | 用 5.6 的 `yaml.safe_load` 检查字段 |
| 目标被拒绝（busy） | 上一任务未结束或 `max_rounds: 0` | 先取消旧目标；`max_rounds` ≥ 1 |
| 反馈停在 `NAVIGATING`、无进展 | 目标点位于未知区域/被障碍封死 | RViz 看代价地图；重新标定该点位 |
| 点位连续失败后 abort | 该点确实不可达（窄道/被堵） | 调 `max_retries`、`retry_delay`，或先修地图 |
| 取消后车未立即停 | Nav2 正在执行恢复行为 | 与 `yhs_safety_guard` 联跑，由联锁发零速兜底 |
| 单轮超过 20 min | `dwell` 设过大或限速未收紧 | 缩短 `dwell_time`；确认 `max_vel_x` ≤ 0.3 |
| yaml-cpp 找不到 | 未安装 vendor 包 | `sudo apt install ros-humble-yaml-cpp-vendor` |
