# S3-02 人车混行区的安全联锁

> 场景来源：[二次开发场景实施方案.md](../../二次开发场景实施方案.md) S3-02；清单条目：[二次开发项目清单.md](../../二次开发项目清单.md) 第三阶段 #2。
> 本实验新建 C++ 功能包 `yhs_safety_guard`：把碰撞、跌落、急停、链路超时四类故障收敛为"零速 + 取消导航目标 + 锁定 + 人工复位"的确定动作，状态机 6 态可解释、可留痕。
> 约定：下文 `WS="$HOME/ros2_ws"`。

## 2. 实验目标

1. 能画出并解释 6 态安全状态机（STARTING/NORMAL/WARNING/STOPPING/LOCKED/RESETTING）的迁移条件与优先级。
2. 能订阅 `/chassis_info_fb` 提取 6 路碰撞、6 路跌落、`io_fb_estop` 与链路时间戳，构成 4 类故障判据。
3. 能向 `/cmd_vel` 发布零速，并用 `rclcpp_action` 的 `NavigateToPose` 客户端调用 `async_cancel_all_goals()` 取消在执行的导航目标。
4. 能通过 `std_srvs/Trigger` 服务实现"故障消除后人工复位"，拒绝在故障未消除时复位。
5. 能实测四类故障的停车时延 ≤ 0.3 s，并证明正常行驶 8 h 无误触发。

### 6.3 `src/safety_guard_node.cpp`

```cpp
#include <chrono>
#include <memory>
#include <mutex>
#include <set>
#include <string>

#include "geometry_msgs/msg/twist.hpp"
#include "nav2_msgs/action/navigate_to_pose.hpp"
#include "rclcpp/rclcpp.hpp"
#include "rclcpp_action/rclcpp_action.hpp"
#include "std_msgs/msg/string.hpp"
#include "std_srvs/srv/trigger.hpp"
#include "yhs_can_interfaces/msg/chassis_info_fb.hpp"

using ChassisInfoFb = yhs_can_interfaces::msg::ChassisInfoFb;
using NavigateToPose = nav2_msgs::action::NavigateToPose;
using Clock = std::chrono::steady_clock;

class SafetyGuardNode : public rclcpp::Node
{
public:
  SafetyGuardNode() : Node("yhs_safety_guard")
  {
    declare_parameter("chassis_topic", "/chassis_info_fb");
    declare_parameter("cmd_vel_topic", "/cmd_vel");
    declare_parameter("navigate_action", "/navigate_to_pose");
    declare_parameter("publish_rate", 20.0);
    declare_parameter("link_timeout", 0.5);
    declare_parameter("link_warn", 0.3);
    declare_parameter("lock_duration", 3.0);
    declare_parameter("startup_grace", 2.0);
    declare_parameter("reset_confirm", 1.0);
    declare_parameter("require_manual_reset", true);

    rate_ = get_parameter("publish_rate").as_double();
    link_timeout_ = get_parameter("link_timeout").as_double();
    link_warn_ = get_parameter("link_warn").as_double();
    lock_duration_ = get_parameter("lock_duration").as_double();
    grace_ = get_parameter("startup_grace").as_double();
    reset_confirm_ = get_parameter("reset_confirm").as_double();
    require_manual_ = get_parameter("require_manual_reset").as_bool();

    zero_pub_ = create_publisher<geometry_msgs::msg::Twist>(
      get_parameter("cmd_vel_topic").as_string(), rclcpp::QoS(1));
    state_pub_ = create_publisher<std_msgs::msg::String>("/safety_guard/state", 10);
    sub_ = create_subscription<ChassisInfoFb>(
      get_parameter("chassis_topic").as_string(), rclcpp::QoS(1).reliable(),
      [this](const ChassisInfoFb::SharedPtr m) {
        std::lock_guard<std::mutex> lock(mutex_);
        data_ = *m; last_rx_ = Clock::now(); has_data_ = true;
      });
    nav_client_ = rclcpp_action::create_client<NavigateToPose>(
      this, get_parameter("navigate_action").as_string());
    reset_srv_ = create_service<std_srvs::srv::Trigger>(
      "/safety_guard/reset",
      [this](const std::shared_ptr<std_srvs::srv::Trigger::Request>,
        std::shared_ptr<std_srvs::srv::Trigger::Response> res) {on_reset(res);});
    timer_ = create_wall_timer(
      std::chrono::milliseconds(static_cast<int>(1000.0 / rate_)), [this]() {tick();});
    start_ = Clock::now();
    RCLCPP_INFO(get_logger(),
      "安全联锁已启动：4 类故障 → 零速 + 取消导航 + 锁定 %.1f s，复位服务 /safety_guard/reset",
      lock_duration_);
  }

private:
  enum class State {STARTING, NORMAL, WARNING, STOPPING, LOCKED, RESETTING};

  static const char * sname(State s)
  {
    switch (s) {
      case State::STARTING: return "STARTING";
      case State::NORMAL: return "NORMAL";
      case State::WARNING: return "WARNING";
      case State::STOPPING: return "STOPPING";
      case State::LOCKED: return "LOCKED";
      default: return "RESETTING";
    }
  }

  static std::string join(const std::set<std::string> & v)
  {
    std::string out;
    for (const auto & s : v) {if (!out.empty()) out += ","; out += s;}
    return out;
  }

  std::set<std::string> triggers(const Clock::time_point & now) const
  {
    std::set<std::string> t;
    if (!has_data_) {t.insert("无底盘数据"); return t;}
    if (now - last_rx_ > std::chrono::duration<double>(link_timeout_)) t.insert("链路超时");
    const auto & io = data_.io_fb;
    if (io.io_fb_estop) t.insert("急停");
    const bool imp[6] = {io.io_fb_fl_impact_sensor, io.io_fb_fm_impact_sensor,
      io.io_fb_fr_impact_sensor, io.io_fb_rl_impact_sensor,
      io.io_fb_rm_impact_sensor, io.io_fb_rr_impact_sensor};
    const bool drp[6] = {io.io_fb_fl_drop_sensor, io.io_fb_fm_drop_sensor,
      io.io_fb_fr_drop_sensor, io.io_fb_rl_drop_sensor,
      io.io_fb_rm_drop_sensor, io.io_fb_rr_drop_sensor};
    static const char * pos[6] = {"左前", "中前", "右前", "左后", "中后", "右后"};
    for (int i = 0; i < 6; ++i) {
      if (imp[i]) t.insert(std::string("碰撞_") + pos[i]);
      if (drp[i]) t.insert(std::string("跌落_") + pos[i]);
    }
    return t;
  }

  std::set<std::string> warnings(const Clock::time_point & now) const
  {
    std::set<std::string> w;
    if (has_data_ && now - last_rx_ > std::chrono::duration<double>(link_warn_)) w.insert("链路延迟");
    if (has_data_ && data_.io_fb.io_fb_joypad_ctrl) w.insert("手柄接管");
    return w;
  }

  void tick()
  {
    std::lock_guard<std::mutex> lock(mutex_);
    const auto now = Clock::now();
    if (now - start_ < std::chrono::duration<double>(grace_)) {
      publish_state();
      return;
    }
    if (state_ == State::STARTING) transition(State::NORMAL, "启动自检完成");

    const auto trig = triggers(now);
    const auto warn = warnings(now);

    if (state_ == State::NORMAL || state_ == State::WARNING) {
      if (!trig.empty()) {
        transition(State::STOPPING, "触发：" + join(trig));
        cancel_goals();
        stop_until_ = now + cast(lock_duration_);
      } else if (!warn.empty() && state_ == State::NORMAL) {
        transition(State::WARNING, "告警：" + join(warn));
      } else if (warn.empty() && state_ == State::WARNING) {
        transition(State::NORMAL, "告警解除");
      }
    } else if (state_ == State::STOPPING) {
      publish_zero();
      if (now >= stop_until_) {
        if (require_manual_) {
          transition(State::LOCKED, "锁定，等待人工复位");
        } else {
          transition(State::NORMAL, "锁定时长到，自动恢复");
        }
      }
    } else if (state_ == State::LOCKED) {
      publish_zero();
      if (!require_manual_ && trig.empty()) transition(State::NORMAL, "故障消除，自动恢复");
    } else if (state_ == State::RESETTING) {
      if (!trig.empty()) transition(State::STOPPING, "复位前再次触发：" + join(trig));
      else if (now >= reset_until_) transition(State::NORMAL, "复位确认完成");
    }
    publish_state();
  }

  static Clock::duration cast(double sec)
  {
    return std::chrono::duration_cast<Clock::duration>(std::chrono::duration<double>(sec));
  }

  void transition(State s, const std::string & why)
  {
    if (s == state_) return;
    RCLCPP_WARN(get_logger(), "状态 %s → %s（%s）", sname(state_), sname(s), why.c_str());
    state_ = s; reason_ = why;
  }

  void publish_zero()
  {
    geometry_msgs::msg::Twist z;
    zero_pub_->publish(z);
  }

  void publish_state()
  {
    std_msgs::msg::String m;
    m.data = std::string(sname(state_)) + " | " + (reason_.empty() ? "无" : reason_);
    state_pub_->publish(m);
  }

  void cancel_goals()
  {
    if (!nav_client_->action_server_is_ready()) {
      RCLCPP_WARN(get_logger(), "Nav2 action server 未就绪，跳过取消目标");
      return;
    }
    nav_client_->async_cancel_all_goals();
    RCLCPP_WARN(get_logger(), "已请求取消 /navigate_to_pose 上的全部目标");
  }

  void on_reset(const std::shared_ptr<std_srvs::srv::Trigger::Response> & res)
  {
    std::lock_guard<std::mutex> lock(mutex_);
    if (state_ != State::LOCKED) {
      res->success = false; res->message = "当前状态 " + std::string(sname(state_)) + " 无需复位";
      return;
    }
    const auto trig = triggers(Clock::now());
    if (!trig.empty()) {
      res->success = false; res->message = "故障未消除：" + join(trig);
      RCLCPP_ERROR(get_logger(), "复位被拒绝：%s", res->message.c_str());
      return;
    }
    state_ = State::RESETTING;
    reset_until_ = Clock::now() + cast(reset_confirm_);
    reason_ = "人工复位受理";
    res->success = true; res->message = "复位已受理，确认后恢复 NORMAL";
    RCLCPP_WARN(get_logger(), "人工复位受理，%.1f s 后恢复 NORMAL", reset_confirm_);
  }

  rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr zero_pub_;
  rclcpp::Publisher<std_msgs::msg::String>::SharedPtr state_pub_;
  rclcpp::Subscription<ChassisInfoFb>::SharedPtr sub_;
  rclcpp::Service<std_srvs::srv::Trigger>::SharedPtr reset_srv_;
  rclcpp_action::Client<NavigateToPose>::SharedPtr nav_client_;
  rclcpp::TimerBase::SharedPtr timer_;
  std::mutex mutex_;
  ChassisInfoFb data_;
  Clock::time_point start_, last_rx_{Clock::now()}, stop_until_{}, reset_until_{};
  State state_{State::STARTING};
  std::string reason_{"启动自检"};
  bool has_data_{false}, require_manual_{true};
  double rate_{20.0}, link_timeout_{0.5}, link_warn_{0.3}, lock_duration_{3.0};
  double grace_{2.0}, reset_confirm_{1.0};
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<SafetyGuardNode>());
  rclcpp::shutdown();
  return 0;
}
```

### 6.4 `config/safety_guard.yaml`

```yaml
yhs_safety_guard:
  ros__parameters:
    chassis_topic: "/chassis_info_fb"
    cmd_vel_topic: "/cmd_vel"
    navigate_action: "/navigate_to_pose"
    publish_rate: 20.0            # 状态机周期，也是零速发布率

    link_warn: 0.3                # 0.3~0.5 s 之间 → WARNING
    lock_duration: 3.0            # STOPPING 持续时长，之后进入 LOCKED
    startup_grace: 2.0            # 启动宽限，避免首帧未到即误停
    reset_confirm: 1.0            # 复位受理后的确认延时
    require_manual_reset: true    # true：必须调用服务；false：故障消除后自动恢复
```

四类故障注入（先 `pkill -f yhs_can_control_node` 停真实底盘节点，再发合成反馈，避免两发布者互相覆盖）：

```bash
# ① 急停
ros2 topic pub -r 20 /chassis_info_fb yhs_can_interfaces/msg/ChassisInfoFb "{io_fb: {io_fb_estop: true}}"
# ② 碰撞（左前）
ros2 topic pub -r 20 /chassis_info_fb yhs_can_interfaces/msg/ChassisInfoFb "{io_fb: {io_fb_fl_impact_sensor: true}}"
# ③ 跌落（右后）
ros2 topic pub -r 20 /chassis_info_fb yhs_can_interfaces/msg/ChassisInfoFb "{io_fb: {io_fb_rr_drop_sensor: true}}"
# ④ 链路超时：Ctrl+C 停掉上面的发布，0.5 s 内即触发
```

终端 B 预期日志：

```text
[WARN] [yhs_safety_guard]: 状态 NORMAL → STOPPING（触发：急停）
[WARN] [yhs_safety_guard]: 已请求取消 /navigate_to_pose 上的全部目标
[WARN] [yhs_safety_guard]: 状态 STOPPING → LOCKED（锁定，等待人工复位）
```

终端 C 同步变为 `STOPPING | 触发：急停` → `LOCKED | 锁定，等待人工复位`；终端 D 由 `0.0` 持续输出。目标取消核对：

```bash
ros2 topic echo /navigate_to_pose/_action/status --field status_list
```

预期出现 `status: 3`（CANCELING）随后 `status: 5`（CANCELED）；Nav2 终端出现 `Canceling all goals`。

人工复位（急停仍按下时应被拒绝）：

```bash
ros2 service call /safety_guard/reset std_srvs/srv/Trigger "{}"
```

预期：故障未消除时 `success=False, message='故障未消除：急停'`；先停合成反馈、重新 `ros2 launch yhs_can_control yhs_can_control.launch.py` 恢复真实反馈后再调用，得到 `success=True, message='复位已受理，确认后恢复 NORMAL'`，1 s 后 C 终端回到 `NORMAL`。

时延取证（判定 ≤ 0.3 s）：

```bash
ros2 bag record -o s302_estop /chassis_info_fb /cmd_vel /safety_guard/state /diagnostics
```

判定标准：4 类故障均进入 STOPPING 并在 0.3 s 内出现零速；LOCKED 期间 `ros2 service call` 之外的任何话题都无法解除；故障消除并复位后回到 NORMAL；正常跑 8 h 无误触发。

## 9. 验收指标

| 维度 | 量化要求 | 判定方法 |
|---|---|---|
| 功能完整性 | 4 类故障 100% 触发；6 态迁移无歧义、日志可追溯 | 8 节四类注入 + 状态日志表 |
| 功能完整性 | 复位流程标准化：故障未消除必须拒绝，复位后 1 s 内回 NORMAL | `ros2 service call` 正反两组 |
| 安全性 | 触发至 `/cmd_vel` 归零 ≤ 0.3 s，滑行 ≤ 0.05 m | bag 时间戳 + 卷尺测滑行 |
| 安全性 | LOCKED 期间仅本服务可解除，远程话题无法解锁 | 锁定中发 `/cmd_vel`、`/navigate_to_pose` 各 1 次 |
| 稳定性 | 连续 8 h 运行误触发 0 次；故障后自检通过率 100% | 8 h 挂机 + 20 次注入循环 |

## 10. 回滚与常见问题

```bash
# 1) 先让车停稳：Ctrl+C 停 B 终端；确认 /cmd_vel 无速度
rm -rf "$WS"/build/yhs_safety_guard "$WS"/install/yhs_safety_guard
rm -rf "$WS"/src/yhs_safety_guard
source "$WS"/install/setup.bash && ros2 pkg list | grep yhs_safety_guard   # 应无输出
git -C "$WS" status --short                                                 # 应无残留
```

| 现象 | 原因 | 处理 |
|---|---|---|
| 状态长期 `STARTING` | `startup_grace` 被改大，或节点刚启动 | 等 `startup_grace` 秒；`ros2 param get /yhs_safety_guard startup_grace` |
| 一直 `WARNING` | 手柄接管中，或链路 0.3~0.5 s 抖动 | 松开手柄；提高 `link_warn` 或排查 CAN 丢帧 |
| 发了零速但车还在动 | `/cmd_vel` 另有发布者（TEB 直连或 `velocity_smoother` 输出到别的话题） | `ros2 topic info /cmd_vel -v`；把 `cmd_vel_topic` 改到最终话题 |
| 目标未取消 | Nav2 命名空间不同，或 action 名不是 `/navigate_to_pose` | `ros2 action list`；改 `navigate_action` 参数 |
| 复位总是被拒 | 故障（急停/碰撞/链路）仍未消除 | 看返回的 `message` 列出的触发项，逐项消除 |
| 停车时延 > 0.3 s | `publish_rate` 过低（如 5 Hz），或 CPU 打满 | 保持 20 Hz；用 `top` 看 `yhs_safety_guard` CPU |
| 编译报找不到 `rclcpp_action` | 依赖未安装或未写进 package.xml | `sudo apt install ros-humble-rclcpp-action`，确认 6.1 已声明 |
| 启动即报 `action server 未就绪` | Nav2 尚未 active（正常，首次可能打印一次） | 等 Nav2 active 后再测；不影响非导航故障联锁 |
