## 2. 实验目标

1. 能说出 `/scan` 的发布 QoS 是 `SensorDataQoS`（BEST_EFFORT、KEEP_LAST(5)），并说明订阅端必须用同等或更宽松策略。
2. 能实现 10 s 采样窗口，统计帧率、平均有效点数、最近有效距离三个指标。
3. 能区分三种退化状态：脏污（点数下降、最近距离不降）、遮挡（点数骤降且最近距离变小）、断线（帧率归零）。
4. 能把三指标映射为"通过/不通过 + 具体原因"的结论，并返回可被脚本消费的退出码，1 min 内完成一次开班点检。

### 5.1 写入完整脚本

把下面全文写入 `~/yhs_labs/S2-07/scan_check.py`：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""S2-07 开班前激光健康自检：10 s 采样，统计频率/有效点数/最近距离并给出结论。"""

import math
import sys
import time

import rclpy
from rclpy.node import Node
from rclpy.qos import SensorDataQoS
from sensor_msgs.msg import LaserScan

RED, YEL, GRN, RST = '\033[31m', '\033[33m', '\033[32m', '\033[0m'


class ScanCheck(Node):
    """只订阅 /scan，按固定窗口统计，不发布任何控制消息。"""

    def __init__(self):
        super().__init__('scan_check_s2_07')
        params = (('scan_topic', '/scan'), ('duration', 10.0), ('min_freq', 8.0),
                  ('max_freq', 12.0), ('min_valid_points', 300),
                  ('min_nearest', 0.05), ('max_nearest', 6.0), ('single_shot', True))
        for name, value in params:
            self.declare_parameter(name, value)
        self.topic = str(self.get_parameter('scan_topic').value)
        self.duration = float(self.get_parameter('duration').value)
        self.min_freq = float(self.get_parameter('min_freq').value)
        self.max_freq = float(self.get_parameter('max_freq').value)
        self.min_pts = int(self.get_parameter('min_valid_points').value)
        self.min_near = float(self.get_parameter('min_nearest').value)
        self.max_near = float(self.get_parameter('max_nearest').value)
        self.single_shot = bool(self.get_parameter('single_shot').value)
        # 与驱动一致：BEST_EFFORT + KEEP_LAST(5)，可靠性与深度都必须兼容
        self.sub = self.create_subscription(
            LaserScan, self.topic, self.on_scan, SensorDataQoS())
        self.meta = {}
        self.reset()
        self.finished = False
        self.exit_code = 0
        self.window_no = 0
        self.create_timer(0.2, self.tick)
        self.get_logger().info(f'激光自检已启动：{self.topic}，窗口 {self.duration:.1f} s，'
                               f'频率判据 {self.min_freq:.0f}~{self.max_freq:.0f} Hz')

    def reset(self):
        self.t0 = None
        self.t_last = None
        self.count = 0
        self.valid_sum = 0
        self.nearest = float('inf')
        self.last_bins = 0

    def on_scan(self, msg):
        now = time.monotonic()      # 单调时钟：系统对时也不会让窗口统计跳变
        if self.t0 is None:
            self.t0 = now
            self.meta = {
                'frame': msg.header.frame_id,
                'angle': (math.degrees(msg.angle_min), math.degrees(msg.angle_max)),
                'range': (msg.range_min, msg.range_max),
            }
        self.t_last = now
        self.count += 1
        self.last_bins = len(msg.ranges)
        valid = 0
        for r in msg.ranges:
            # 驱动对无效点填 0，并用 inf 表示超量程；两者都要剔除
            if math.isfinite(r) and r > 0.0 and msg.range_min <= r <= msg.range_max:
                valid += 1
                if r < self.nearest:
                    self.nearest = r
        self.valid_sum += valid

    def tick(self):
        if self.t0 is None:
            return
        elapsed = self.t_last - self.t0
        if self.count < 2 or elapsed < self.duration:
            return
        self.report(elapsed)

    def verdict(self, freq, mean_valid, nearest):
        reasons = []
        if not (self.min_freq <= freq <= self.max_freq):
            reasons.append(f'频率 {freq:.1f} Hz 不在 {self.min_freq:.0f}~{self.max_freq:.0f} Hz')
        if mean_valid < self.min_pts:
            reasons.append(f'平均有效点 {mean_valid:.0f} < {self.min_pts}')
        if not math.isfinite(nearest):
            reasons.append('10 s 内没有任何有效回波')
        elif not (self.min_near <= nearest <= self.max_near):
            reasons.append(f'最近距离 {nearest:.2f} m 不在 {self.min_near:.2f}~'
                           f'{self.max_near:.2f} m')
        return reasons

    def report(self, elapsed):
        self.window_no += 1
        freq = (self.count - 1) / elapsed
        mean_valid = self.valid_sum / self.count
        ratio = mean_valid / self.last_bins * 100.0 if self.last_bins else 0.0
        reasons = self.verdict(freq, mean_valid, self.nearest)
        ok = not reasons
        self.exit_code = 0 if ok else 1
        color = GRN if ok else RED
        print('=' * 58)
        print(f'激光健康自检 第 {self.window_no} 次  窗口 {elapsed:.1f} s')
        print(f'话题 {self.topic}  frame={self.meta["frame"]}  '
              f'角度 [{self.meta["angle"][0]:.1f}, {self.meta["angle"][1]:.1f}]°  '
              f'量程 [{self.meta["range"][0]:.3f}, {self.meta["range"][1]:.1f}] m')
        print(f'帧数 {self.count}    频率 {freq:.1f} Hz')
        print(f'平均有效点 {mean_valid:.0f} / {self.last_bins}（{ratio:.1f}%）    '
              f'最近距离 {"inf" if not math.isfinite(self.nearest) else f"{self.nearest:.2f} m"}')
        print(color + ('判定：通过' if ok else '判定：不通过 —— ' + '；'.join(reasons)) + RST)
        print('=' * 58, flush=True)
        if ok:
            self.get_logger().info(f'自检通过：{freq:.1f} Hz，有效点 {mean_valid:.0f}，'
                                   f'最近 {self.nearest:.2f} m')
        else:
            self.get_logger().error('自检不通过：' + '；'.join(reasons))
        if self.single_shot:
            self.finished = True
        else:
            self.reset()


def main(args=None):
    rclpy.init(args=args)
    node = ScanCheck()
    try:
        while rclpy.ok() and not node.finished:
            rclpy.spin_once(node, timeout_sec=0.1)
    except KeyboardInterrupt:
        pass
    finally:
        code = node.exit_code
        if node.t0 is None:
            node.get_logger().error(f'{node.topic} 在 {node.duration:.0f} s 内没有收到任何数据')
            code = 2
        node.destroy_node()
        if rclpy.ok():
            rclpy.shutdown()
    sys.exit(code)


if __name__ == '__main__':
    main()
```

### 5.3 三态复现

1. 正常：清空雷达视窗，前方 0.4 m 放挡板，运行一次，记录三指标作为基线。
2. 脏污：用无绒布轻擦窗口留下一层薄灰（或贴半透明胶带），再运行一次。预期有效点下降、最近距离变化不大。
3. 遮挡：用纸板遮住约 1/3 视场，运行一次，预期有效点骤降、最近距离变小。
4. 断线：拔出雷达串口（或 `pkill -f nvilidar`），运行一次，预期 10 s 后打印"没有收到任何数据"、退出码 `2`。

| 状态 | 频率 | 有效点 | 最近距离 | 结论示例 |
|---|---|---|---|---|
| 正常 | 9.9 Hz | 682 | 0.41 m | 通过 |
| 脏污 | 9.9 Hz | 310 | 0.43 m | 不通过（点数接近阈值时结合基线判定） |
| 遮挡 | 9.9 Hz | 240 | 0.22 m | 不通过：平均有效点 240 < 300 |
| 断线 | 0 Hz | — | — | 不通过：10 s 内没有任何数据（退出码 2） |

## 6. 关键代码与配置

| 代码段 | 作用 | 关键点 |
|---|---|---|
| `SensorDataQoS()` | 订阅 QoS | 等价于 BEST_EFFORT + KEEP_LAST(5)，与 `nvilidar_ros2_node.cpp` 的 `create_publisher(..., SensorDataQoS())` 完全匹配 |
| `math.isfinite(r) and r > 0` | 有效点判定 | 驱动对无效点填 0、超量程填 inf；0 也小于 `range_min`，三道条件缺一不可 |
| `time.monotonic()` | 时间基准 | 不用系统墙钟，避免 NTP 对时导致频率算错 |
| `count-1 / (t_last-t0)` | 频率估计 | 用首末帧间隔而非窗口名义长度，避免最后一帧抖动带来的偏差 |
| `verdict()` | 三指标 → 原因列表 | 每个不通过项都给可读原因，便于操作手直接处置 |
| `single_shot` + 外部 `spin_once` 循环 | 单次点检/连续监视 | 不在回调里 `shutdown()`，避免 rclpy 上下文被提前销毁 |

| 参数 | 默认 | 说明 |
|---|---|---|
| `duration` | 10.0 | 采样窗口（s） |
| `min_freq` / `max_freq` | 8.0 / 12.0 | 频率合格区间（Hz），对应 `aim_speed: 10.0` |
| `min_valid_points` | 300 | 平均有效点数下限，建议按现场基线取 40%~50% |
| `min_nearest` / `max_nearest` | 0.05 / 6.0 | 最近距离合理区间（m） |

对照仓库配置：[nvilidar.yaml](../../../src/hardware/nvilidar_ros2/params/nvilidar.yaml) 中 `range_min: 0.001`、`range_max: 64.0`、`aim_speed: 10.0`、`frame_id: "laser_link"`。若现场改过 `ignore_array_string` 屏蔽角度，有效点分母应扣除被屏蔽扇区，否则会误判为"点数不足"。

## 10. 回滚与常见问题

回滚：①`Ctrl+C` 退出脚本（无副作用）；②`rm -rf ~/yhs_labs/S2-07`；③`git status` 应无新增；④本实验不改雷达参数、不占用控制链路，无需还原配置；⑤若为复现脏污贴过胶带，务必清除干净再交班。

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直无输出，10 s 后报"没有收到任何数据" | QoS 不兼容（订阅端写成 RELIABLE）或雷达未起 | 保持 `SensorDataQoS()`；先 `ros2 topic hz /scan` 确认驱动正常 |
| 频率只有 4~5 Hz | USB 带宽不足或 `aim_speed` 被改小 | 换 USB 3.0 口；核对 `nvilidar.yaml` 的 `aim_speed: 10.0` |
| 有效点长期低于 300 | 雷达脏污、屏蔽角过宽、量程被改小 | 清洁窗口；核对 `ignore_array_string` 与 `range_max` |
| 最近距离恒定 0.05 m 左右 | 机身支架进入盲区 | 在 `ignore_array_string` 屏蔽固定角度，再重取基线 |
| 退出码始终 1（课堂场地太空旷） | `max_nearest` 默认 6.0 过严 | `--ros-args -p max_nearest:=10.0`，并在点检表注明场地条件 |
