## 2. 实验目标

1. 能说明「通道能否被规划」由全局代价地图的膨胀层决定，「贴边是否安全」由 TEB 的障碍距离参数决定，二者不可混为一谈。
2. 找出并修正本仓库的真实配置缺陷：`local_costmap` 写了 `inflation_layer` 参数段却未把该层加入 `plugins`，局部膨胀参数长期不生效。
3. 把 `footprint` 改为卷尺实测值后，局部与全局两个代价地图回读字符串一致，且与实测车体偏差 ≤ 0.02 m。
4. 3 条窄巷道均可规划、可通行，20 次通行无卡死、无恢复行为触发。
5. 通行全程 `/cmd_vel` 线速度 ≤ 0.15 m/s，贴边最小间距 ≥ 0.10 m。

## 5. 实施步骤

### 步骤 1：勘测巷道与车体轮廓

- **操作说明**：卷尺测量 3 条最窄巷道的净宽（两壁最小距离，每巷 3 个测点）与地面状况；测量车体最大外廓（含防撞条、货架架体、轮胎外沿）。执行目录：任意。
- **可复制命令**：`ls -l "$HOME/yhs_labs/S1-03/result/通道勘测记录.csv"`
- **预期输出示例**：净宽读数集中在 0.88~0.92 m，共 9 个测点记录。
- **完成标志**：3 条巷道 × 3 测点填写完整，车体实测长 × 宽已记录。

### 步骤 2：更新 footprint 与两处膨胀层

- **操作说明**：把实测半长、半宽写进局部与全局 `footprint`（示例按 0.58 m × 0.48 m，**必须用实测值替换**）；把 `inflation_layer` 加入局部 `plugins` 并改为设计值，再改全局 `cost_scaling_factor`。执行目录：`$WS`。
- **可复制命令**：

```bash
cd "$WS"
grep -n "footprint:\|plugins:" src/yhs_nav2/param/yhs_nav2.yaml
sed -n '245,255p;323,326p' src/yhs_nav2/param/yhs_nav2.yaml
```

- **预期输出示例**：局部 `plugins: ["static_layer", "obstacle_layer", "inflation_layer"]`；两处 `footprint` 字符串相同；两处 `cost_scaling_factor` 均为 `5.0`。
- **完成标志**：`inflation_layer` 位于 `plugins` 最后一位；半宽 ≤ 0.45 − 0.10 = 0.35 m（保证 0.9 m 巷道两侧各留 ≥ 0.10 m）。

### 步骤 3：TEB 障碍距离与限速联动

- **操作说明**：`min_obstacle_dist: 0.45` 等于 0.9 m 巷道的半净宽，控制层必然判不可行，需与规划层同步放宽；同时把线速度压到 0.15 m/s。执行目录：`$WS`。
- **可复制命令**：

```bash
cd "$WS" && grep -n "min_obstacle_dist\|inflation_dist\|max_vel_x:" src/yhs_nav2/param/yhs_nav2.yaml
```

- **预期输出示例**：`min_obstacle_dist: 0.15`、`inflation_dist: 0.25`、`max_vel_x: 0.15`。
- **完成标志**：三处均位于 `FollowPath:` 下（6 空格）；若已完成 S1-01，`velocity_smoother.max_velocity` 同步为 `[0.15, 0.0, 0.3]`。

### 步骤 4：低速通行 10 次 + 动态障碍绕行

- **操作说明**：向 3 条巷道逐一发目标往返通行，记录左右最小间距与恢复行为；随后在巷道中段放置 1 个锥桶（占单侧 ≤ 0.3 m）再走 3 次。执行目录：`$WS`。
- **可复制命令**：

```bash
cd "$WS"
ros2 param get /local_costmap/local_costmap plugins
ros2 topic echo /behavior_tree_log | tee "$HOME/yhs_labs/S1-03/result/bt_log.txt"
```

- **预期输出示例**：`StringArray value is: [static_layer, obstacle_layer, inflation_layer]`；日志中不出现 `Spin`、`BackUp`、`Wait`。
- **完成标志**：10 次通行最小间距 ≥ 0.10 m；3 次绕行成功且不越过货架边界线。

## 6. 关键配置与代码

文件路径：`~/ros2_ws/src/yhs_nav2/param/yhs_nav2.yaml`

### 6.1 改动点 A：局部代价地图（`local_costmap` → `local_costmap`）

替换位置：基线第 245~255 行整段（含 `footprint`、`plugins`、`inflation_layer`）。

```yaml
      rolling_window: true
      width: 6
      height: 6
      resolution: 0.05
      footprint: "[[0.29,0.24],[0.29,-0.24],[-0.29,-0.24],[-0.29,0.24]]"
      plugins: ["static_layer", "obstacle_layer", "inflation_layer"]
      inflation_layer:
        plugin: "nav2_costmap_2d::InflationLayer"
        inflation_radius: 0.55
        cost_scaling_factor: 5.0
```

### 6.2 改动点 B：全局代价地图（`global_costmap` → `global_costmap`）

替换位置一：基线第 292 行 `footprint`；替换位置二：基线第 323~326 行 `inflation_layer`。

```yaml
      footprint: "[[0.29,0.24],[0.29,-0.24],[-0.29,-0.24],[-0.29,0.24]]"
```

```yaml
      inflation_layer:
        plugin: "nav2_costmap_2d::InflationLayer"
        cost_scaling_factor: 5.0
        inflation_radius: 0.55
```

### 6.3 改动点 C：TEB 障碍距离与限速（`FollowPath`）

替换位置：基线第 148 行 `max_vel_x`、第 165~167 行 `# Obstacles` 小节。

```yaml
      # Obstacles 
      min_obstacle_dist: 0.15
      inflation_dist: 0.25
```

```yaml
      max_vel_x: 0.15
```

| 参数 | 原值 | 新值 | 含义与影响 |
|---|---|---|---|
| `local_costmap.plugins` | `["static_layer", "obstacle_layer"]` | 追加 `inflation_layer` | 让局部膨胀参数真正被加载（当前是失效配置） |
| `local_costmap.inflation_layer.inflation_radius` | 1.0（未生效） | 0.55 | 与全局一致，避免两套代价图行为冲突 |
| `local_costmap.inflation_layer.cost_scaling_factor` | 3.0（未生效） | 5.0 | 梯度更陡，路径倾向居中 |
| `global_costmap.inflation_layer.cost_scaling_factor` | 3.0 | 5.0 | 决定窄巷道中心栅格代价，是「能否规划」的关键 |
| `global_costmap.inflation_layer.inflation_radius` | 0.55 | 0.55（保持） | 与方案目标值一致，本实验不改 |
| `footprint`（两处） | `[[0.30,0.26],[0.30,-0.26],[-0.30,-0.26],[-0.30,0.26]]`（0.60 m × 0.52 m） | 实测值（示例 0.58 m × 0.48 m） | 内切半径随半宽变化，直接影响膨胀起点；偏大判死窄道，偏小会刮碰 |
| `FollowPath.min_obstacle_dist` | 0.45 | 0.15 | 硬约束障碍间距；0.45 ≥ 半净宽 0.45，必然不可行 |
| `FollowPath.inflation_dist` | 0.6 | 0.25 | 软约束膨胀距离，0.6 会持续把车推向巷道中心并导致无解 |
| `FollowPath.max_vel_x` | 0.2（S1-01 后）或 0.5（原始） | 0.15 | 窄巷道验收要求全程 ≤ 0.15 m/s |

### 6.4 取值校核与可选微调

- 通行几何：巷道半净宽 0.45 m；`footprint` 半宽 + `min_obstacle_dist` = 0.24 + 0.15 = 0.39 m ≤ 0.45 m，余量 0.06 m。
- 贴边间距若 < 0.10 m，可把两处代价地图的 `footprint_padding` 由默认 0.01 提到 0.02，比放大 `footprint` 更安全。

### 10.2 常见问题

| 报错文本 / 现象 | 原因 | 处理步骤 |
|---|---|---|
| `Parameter not set`（局部膨胀） | `inflation_layer` 未加入 `local_costmap.plugins` | 按 6.1 节补齐，且放在 `plugins` 最后一位 |
| `Error parsing footprint parameter: ...` 与 `Footprint string was '...'` | 括号、逗号或引号不匹配 | 严格按 `"[[x,y],[x,y],[x,y],[x,y]]"` 书写，四角按逆时针顺序 |
| `You must specify at least three points for the robot footprint, reverting to previous footprint.` | 角点不足 3 个（漏了一对角点） | 补齐 4 个角点后重启 launch |
| `teb_local_planner was not able to obtain a local plan for the current setting.` | `min_obstacle_dist` 或 `inflation_dist` 仍大于半净宽 | 回读 `FollowPath.min_obstacle_dist`，按 6.4 节几何校核重算 |
| 全局路径生成但一进巷道就停 | 只放开了膨胀，没放开 TEB 障碍距离 | 同时核对 6.1 与 6.3 两节 |
| 规划绕远、始终不进巷道 | 静态地图中巷道被噪声点封住，或梯度仍为 3.0 | RViz 放大看巷道内残留障碍；回读 `cost_scaling_factor` |
| 车体轻微刮碰货架 | `footprint` 实测偏小（漏算防撞条/轮胎外沿） | 重新实测，或把 `footprint_padding` 提到 0.02 |
