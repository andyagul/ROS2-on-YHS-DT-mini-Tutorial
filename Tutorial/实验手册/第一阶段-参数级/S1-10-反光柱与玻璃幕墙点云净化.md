## 2. 实验目标

1. 测绘并记录每个固定鬼影的**角度区间与对应实体**，形成"鬼影角度表"（每个鬼影必须有可解释实体，不允许凭感觉填数）。
2. 按 `ignore_array_string` 格式规则（逗号分隔、**成对**、偶数个、单位度、雷达**逆时针**）写出合法字符串，屏蔽总宽度 ≤ 30°。
3. 说明并验证 `angle_offset` 必须配合 `angle_offset_change_flag: true` 才会下发到雷达。
4. RViz 中固定鬼影消失，屏蔽区外有效点保留率 ≥ 95%。
5. `/scan` 频率稳定 10 Hz ± 1，长跑无异常跳变（课堂以 30 min 代替 4 h 并注明）。

## 6. 关键配置与代码

**文件**：`src/hardware/nvilidar_ros2/params/nvilidar.yaml`
**位置**：`nvilidar_ros2_node: ros__parameters:` 下（第 8、15~25 行）
**改动**：只改参数值，不增删键名，保持 4 空格缩进。

```yaml
nvilidar_ros2_node:
  ros__parameters:
    frame_id: "laser_link"
    range_min: 0.10              # 原值 0.001
    range_max: 20.0              # 原值 64.0
    sensitive: false             # 需按强度剔除玻璃点时可改 true（可选）
    tailing_level: 10            # 原值 20
    angle_offset_change_flag: true   # 原值 false，必须为 true 才写入雷达
    angle_offset: -1.5           # 原值 0.0，按实测安装角偏差填写
    ignore_array_string: "62,68,118,124,236,242"   # 原值 ""
```

其余键（`serialport_name: "/dev/lidar"`、`serialport_baud: 512000`、`angle_min: -180.0`、`angle_max: 180.0`、`apd_change_flag: false` 等）保持不变，插入位置即上述各键原有行，不要新增键名。

| 参数 | 原值 | 新值 | 含义与影响 |
|---|---|---|---|
| `ignore_array_string` | `""` | `"62,68,118,124,236,242"` | 按角度区间丢弃点，格式见专项说明 |
| `angle_offset` | `0.0` | 实测值（示例 `-1.5`） | 雷达安装角相对车头正前方的偏差，用于整圈点云纠偏 |
| `angle_offset_change_flag` | `false` | `true` | **下发开关**：仅 `true` 时驱动才把偏移写入雷达（`nvilidar_driver_serialport.cpp` 第 128 行） |
| `tailing_level` | `20` | `10` | 雷达端拖尾过滤等级；README 明确"越小过滤越强" |
| `range_min` | `0.001` | `0.10` | 最小有效距离，剔除贴身噪点；小于该值的点被置 0 |
| `range_max` | `64.0` | `20.0` | 最大有效距离，室内 20 m 足够，可剔除玻璃远距反射 |
| `frame_id` | `laser_link` | 保持 | 必须与静态 TF 子帧名一致，否则 RViz/Cartographer 无法变换 |
| `sensitive` | `false` | 保持 `false`（可选 `true`） | `true` 时 `/scan` 才有有效 `intensities`（README 第 117 行）；若频率或点数明显下降则回退 |

### `ignore_array_string` 格式专项说明

- `README.md` 第 216 行：该参数用于过滤指定角度点，"it is anti-clockwise for the lidar"，示例 `"30,60,90,120"` 表示屏蔽 **30°~60°** 与 **90°~120°** 两段。
- `nvilidar_process.cpp` 第 203~223 行：字符串按英文逗号 `,` 切分为 `float` 数组，**元素个数必须为偶数**（奇数会打印 `ignore array is odd need be even`，随后按 `j` 与 `j+1` 成对访问，存在越界风险）。
- `nvilidar_driver_serialport.cpp` 第 1884~1900 行：每两点组成闭区间 `[start, end]`，落在区间内的点**距离与强度置 0**（不是 `inf`）。
- 实操约定：单位写**度**，按 **0~360° 逆时针**（雷达视角）。`/scan` 角度是 `-π~π`，负数加 360 换算（`-95°` → `265°`）。
- 写法要求：区间递增、`start < end`、互不重叠、总宽度 ≤ 30°。

> 安全提醒：被屏蔽点距离置 0，代价地图会当作"无回波"而非"有障碍"。**屏蔽区绝不能覆盖主行驶方向**，否则等于抹掉真实障碍。

## 10. 回滚与常见问题

```bash
# 执行目录：$WS
cd "$WS"
cp ~/yhs_labs/S1-10/backup/nvilidar.yaml.orig src/hardware/nvilidar_ros2/params/nvilidar.yaml
colcon build --symlink-install --packages-select nvilidar_ros2
```

`angle_offset` 是写入雷达配置的，回滚参数文件不会清除雷达内偏移值。彻底还原需先把 `angle_offset: 0.0` 且 flag 为 `true` 运行一次（写入 0），再把 flag 改回 `false`。

| 现象 / 报错 | 原因 | 处理 |
|---|---|---|
| `ignore array is odd need be even` | 元素个数为奇数 | 成对补齐：`"62,68,118"` → `"62,68,118,124"` |
| 屏蔽后鬼影仍在 | 角度方向换算错（把负角直接填进去），或改的是 `src/` 运行的是旧 `install/` | 负角 +360；`ros2 param get /nvilidar_ros2_node ignore_array_string` 回读确认 |
| 改了 `angle_offset` 没效果 | `angle_offset_change_flag` 仍为 `false` | 置 `true` 后重启，观察整圈点云是否平移 |
| 主行驶方向"看不见墙" | 屏蔽区间覆盖正前方，或 `range_max` 过小 | 核对角度表；`range_max` 不小于场地最长对角线 × 1.2 |
| `/scan` 频率跌到 5 Hz 或点数骤减 | `sensitive: true` 或 `tailing_level` 过强 | 回退 `sensitive: false`；`tailing_level` 回调到 15~20 |
| RViz 报 `No transform from [laser_link] to [base_link]` | `frame_id` 与静态 TF 名不一致 | 改回 `laser_link`；TF 由 `nvilidar.launch.py` 提供（z = 0.33） |
| 节点启动即退出，提示打不开雷达串口 | `/dev/lidar` 不存在、权限不足或波特率被改 | `ls -l /dev/lidar`；确认 `serialport_baud: 512000`；检查 `dialout` 组 |
