# S1-08 库区高精度地图采集

> 配套：[二次开发场景实施方案.md](../../二次开发场景实施方案.md)（S1-08）、[二次开发项目清单.md](../../二次开发项目清单.md)（第一阶段 #8）
> 硬件基线：YHS DT-mini 差速 CAN 底盘 + nvilidar 单线激光 + 串口 IMU；软件基线：Ubuntu 22.04 + ROS 2 Humble + Cartographer 2.0
> 本实验只改 `dgt_mini.lua` 参数，不写代码、不换算法。

## 一、实验信息

| 项目 | 内容 |

| 实验编号 | S1-08 |
| 阶段 | 第一阶段：参数级（零代码） |

| 硬件与场地要求 | 500~1000 m² 库区，货架密集且含至少 1 个自然回环；地面平整、光照稳定；采集速度 ≤ 0.2 m/s；急停可达；建议 2 人（1 人推车/遥控，1 人盯 RViz 与日志） |

## 二、实验目标

1. 读出 `dgt_mini.lua` 中子图帧数、优化频率、运动滤波、量程的真实键名与当前值，并说明各值对回环质量与 CPU 的影响。
2. 调参后连续采集 3 轮、每轮 ≥ 15 min 不断图，产出 3 套 `.pgm/.yaml`。
3. 用 `map_saver_cli` 正确保存地图并解释其硬编码路径行为；用两种方法量测闭合误差，3 轮中 ≥ 2 轮 ≤ 0.1 m，完成质检并择优归档交付图。

## 五、实施步骤

**步骤 1：规划闭环路线并做地面标记**

用美纹纸在地面贴 1 个起点十字（可重复对准 `base_link` 投影点）+ 4 个特征点（门框、立柱根部、消防栓前地面）。

| 记录项 | 要求 |
|---|---|
| 起点标记 | 十字贴纸，中心对齐 `base_link` 投影 |
| 路线与覆盖 | 200~400 m（0.2 m/s 下 17~34 min，满足 ≥ 15 min）；每条货架通道至少进入 1 次，回环处不掉头 |
| 安全 | 采集区清场，转角安排 1 名观察员 |

完成标志：《采集路线图》标出起终点、4 个特征点与行进方向，安全员确认。

**步骤 4：采集 3 轮（每轮 ≥ 15 min）**

每轮开始在起点停车 10 s（建立第一帧子图）；全程 ≤ 0.2 m/s，用遥控器或键盘遥控；每轮结束回到起点十字停车 5 s 再停采集。

```bash
ros2 launch yhs_nav2 cartographer.launch.py
ros2 topic echo /tracked_pose --field pose.position --once
ros2 topic hz /map
```

预期：起点读数示例 `x: 0.041` / `y: -0.018` / `z: 0.0`（记入质检表）；采集过程 `/map` 持续 `average rate: 1.00x`，掉到 0 说明建图已断，立即停车排查（见第十节）。

完成标志：3 轮各自 ≥ 15 min 内 `/map` 持续 1 Hz、RViz 地图持续扩展、无可见子图错位。

**步骤 5：保存地图（`map_saver_cli`）**

不要停建图节点，新终端直接保存。本仓库 `nav2_map_server/src/map_saver/main_cli.cpp` 把输出目录硬编码为 `/home/qg/ros2_ws/...`，因此用相对文件名（不带 `/`）并预先创建这两个目录：


预期：`[INFO] [map_saver_cli]: Map saved successfully to both directories.`；若第二份因 `main_cli.cpp` 的 `substr` 越界打印 `Unexpected problem appear: basic_string::substr`，第一份仍已落盘，`cp` 即可取回。

备选（绕开硬编码，路径可任意指定）：

```bash

```

**步骤 6：闭合误差量测**

方法 A（推荐，基于 `/tracked_pose`）：采集前在起点十字停车读一次坐标，例如 `(0.041, -0.018)`；跑完一圈回到同一十字、同一朝向停稳再读一次，例如 `(0.118, -0.052)`：

```bash
ros2 topic echo /tracked_pose --field pose.position --once
python3 -c "import math; print(round(math.hypot(0.118-0.041, -0.052+0.018), 3))"
```

预期：`0.084`，判定 ≤ 0.1 为合格。超差先检查起点是否重复对准，再将 `constraint_builder.min_score` 回调到 0.36 复测。

方法 B（基于地图图像交叉验证）：RViz 加载 `/map`（QoS `Transient Local`）、`LaserScan`（`/scan`，`Best Effort`）、`PoseStamped`（`/tracked_pose`）、`TF`，用 **Measure** 工具量同一面墙在回环处的"双墙间距"，或量起点标记在图上两次出现的距离；像素差 × `resolution`（0.05 m/px）≤ 0.1 m 即 ≤ 2 px。同时看货架直线度：同一货架沿长方向弯曲/重影 ≤ 2 px。

```bash
ros2 run rviz2 rviz2
```

完成标志：《地图质检报告》中 3 轮的闭合误差与重影均有数值。

**步骤 7：择优归档**

```bash

```

预期：`1:image: warehouse_delivery.pgm`、`3:resolution: 0.05`。完成标志：该 yaml 可被 S1-11 的 `map:=` 直接加载。

## 六、关键配置与代码

文件：`src/cartographer_ros/cartographer_ros/configuration_files/dgt_mini.lua`；位置：`options` 表内新增 1 键；`TRAJECTORY_BUILDER_2D.*`、`POSE_GRAPH.*`、`motion_filter` 段逐项改值（第 17~70 行）。

| 参数（真实键名） | 原值 → 新值 | 含义与取舍 |
|---|---|---|
| `options.publish_tracked_pose` | 未设置（默认 false）→ `true` | 发布 `/tracked_pose`，用于闭合误差量测；不影响建图结果 |
| `TRAJECTORY_BUILDER_2D.submaps.num_range_data` | 60 → 90 | 每个子图累计的激光帧数。加大后子图覆盖更长通道、子图数减少，子图间错位点减少 |
| `POSE_GRAPH.optimize_every_n_nodes` | 5 → 10 | 每新增 N 节点做一次全局优化。5 过于频繁（CPU 峰值高、长时采集易抖），10 在 0.1 m 节点间距下约每 1 m 优化一次 |
| `POSE_GRAPH.constraint_builder.min_score` | 0.34 → 0.40 | 回环候选最低匹配得分。货架纹理重复，过低会产生错误回环把地图拉歪 |
| `TRAJECTORY_BUILDER_2D.motion_filter.max_distance_meters` | 0.2 → 0.1 | 插入节点的最小位移；加密节点使回环约束更准，代价是算量上升 |
| `TRAJECTORY_BUILDER_2D.motion_filter.max_angle_radians` | `math.rad(0.1)` → `math.rad(0.05)` | 插入节点的最小转角，转向处更密，抑制转向错层 |
| `TRAJECTORY_BUILDER_2D.min_range` | 0.5 → 0.3 | 近距离有效量程。贴货架时不再整帧丢弃；< 0.3 m 的车体遮挡区仍忽略 |
| `TRAJECTORY_BUILDER_2D.max_range` | 50 → 30 | 库区长边约 40 m，30 m 外回波对配准贡献低，截断降噪 |
| `TRAJECTORY_BUILDER_2D.use_imu_data` | false → false（保持） | IMU 融合属 S1-09 |
| `resolution` | 0.05 → 0.05（保持） | **不在 lua 里**，位于 `dgt_mini.launch.py` 的 `cartographer_occupancy_grid_node` 参数 `{'resolution': 0.05}`，与 `global_costmap` 的 `resolution: 0.05` 对齐 |

```lua
  num_laser_scans = 1,
  num_multi_echo_laser_scans = 0,
  num_subdivisions_per_laser_scan = 1,
  num_point_clouds = 0,
  lookup_transform_timeout_sec = 0.2,
  submap_publish_period_sec = 5e-3,
  pose_publish_period_sec = 30e-3,
  trajectory_publish_period_sec = 1,
  rangefinder_sampling_ratio = 1,
  odometry_sampling_ratio = 1,
  fixed_frame_pose_sampling_ratio = 1.,
  imu_sampling_ratio = 1.,

TRAJECTORY_BUILDER_2D.submaps.num_range_data = 90   -- 原 60
TRAJECTORY_BUILDER_2D.min_range = 0.3               -- 原 0.5
TRAJECTORY_BUILDER_2D.max_range = 30                -- 原 50
TRAJECTORY_BUILDER_2D.missing_data_ray_length = 5

POSE_GRAPH.optimize_every_n_nodes = 10              -- 原 5
```

## 十、回滚与常见问题

```bash
cd ~/"ROS2 on YHS DT-mini Tutorial"
cp ~/yhs_labs/S1-08/backup/dgt_mini.lua.bak src/cartographer_ros/cartographer_ros/configuration_files/dgt_mini.lua
colcon build --symlink-install --packages-select cartographer_ros
source install/setup.bash
```

| 现象 | 原因 | 处理 |
|---|---|---|
| 改完 lua 后 `install/.../dgt_mini.lua` 仍是旧值 | 只改 `src` 未重新 build，或改错另一个 `dgt_mini.lua` | 在工作空间根目录 `colcon build --symlink-install --packages-select cartographer_ros` 后 grep `install` 副本 |
| `map_saver_cli` 报 `Failed to save map to first directory` | `main_cli.cpp` 硬编码 `/home/qg/ros2_ws/src/yhs_nav2/map/`，目录不存在 | 先 `sudo mkdir -p /home/qg/ros2_ws/src/yhs_nav2/map /home/qg/ros2_ws/install/yhs_nav2/share/yhs_nav2/map` 并 `chown`；或改用 `map_saver_server` + `/map_saver/save_map` 指定 `map_url` |
| `Unexpected problem appear: basic_string::substr` | 同一缺陷：第二份保存对短文件名 `substr` 越界 | 忽略报错，第一份已保存，`cp` 取回即可 |
| 地图明显错层或 `Failed to compute submap` | 速度过快导致扫描匹配跟不上；或 `min_score` 过低产生错误回环 | 降到 ≤ 0.15 m/s 重采；`constraint_builder.min_score` 提到 0.45 再试 |
| `/map` 频率掉到 0，地图不再扩展 | 雷达断流、底盘掉线或 `Lost trajectory` | 先 `ros2 topic hz /scan`，再 `ros2 topic hz /odom`，确认 CAN 未掉；必要时重启建图栈并重采该轮 |
| 闭合误差 > 0.15 m 且 3 轮都不合格 | 起点未重复对准、路线未真正闭合、里程计标定偏差 | 重新贴起点并严格对位；里程计标定超出本实验范围，记录后另行评审 |
| `ros2 topic hz /tracked_pose` 无输出 | 未加 `publish_tracked_pose = true` 或未重新编译安装 | 按第六节新增该键并重新 `colcon build --packages-select cartographer_ros` |
