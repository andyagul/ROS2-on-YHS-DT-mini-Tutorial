## 2. 实验目标

1. 能说出 6 路跌落开关的字段名（`io_fb_fl/fm/fr/rl/rm/rr_drop_sensor`）与触发极性（true=跌落）。
2. 能编写 rclpy 节点：任一跌落触发即向 `/cmd_vel` 发布零速 Twist，并保持 5 s。
3. 能通过 Nav2 的标准取消通道 `/navigate_to_pose/_action/cancel_goal` 取消当前导航目标，而不是自造服务。
4. 能实现"触发 → 锁定 → 人工确认复位"状态机，复位必须人工介入。
5. 能实测触发到 `/cmd_vel` 归零的时延 ≤ 0.3 s，并逐路验证 6 个开关。

## 5. 实施步骤

### 5.1 写入完整脚本

把下面全文写入 `~/yhs_labs/S2-03/drop_guard.py`：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""S2-03 月台防跌落停车：6 路跌落任一触发 → 零速 5 s + 取消导航 + 人工复位。"""

import threading
import time

import rclpy
from rclpy.node import Node
from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy

from action_msgs.msg import GoalInfo
from action_msgs.srv import CancelGoal
from geometry_msgs.msg import Twist
from yhs_can_interfaces.msg import ChassisInfoFb

RED, GRN, RST = '\033[31m', '\033[32m', '\033[0m'
DROP = [('左前', 'io_fb_fl_drop_sensor'), ('前中', 'io_fb_fm_drop_sensor'),
        ('右前', 'io_fb_fr_drop_sensor'), ('左后', 'io_fb_rl_drop_sensor'),
        ('后中', 'io_fb_rm_drop_sensor'), ('右后', 'io_fb_rr_drop_sensor')]


class DropGuard(Node):
    """NORMAL → TRIGGERED（零速保持）→ LOCKED（人工回车复位）。"""

    def __init__(self):
        super().__init__('drop_guard_s2_03')
        params = (('hold_seconds', 5.0), ('publish_rate', 20.0), ('cmd_topic', '/cmd_vel'),
                  ('chassis_topic', '/chassis_info_fb'), ('nav_action', '/navigate_to_pose'),
                  ('auto_cancel', True))
        for name, value in params:
            self.declare_parameter(name, value)
        self.hold = float(self.get_parameter('hold_seconds').value)
        self.rate = float(self.get_parameter('publish_rate').value)
        self.cmd_topic = str(self.get_parameter('cmd_topic').value)
        self.chassis_topic = str(self.get_parameter('chassis_topic').value)
        self.nav_action = str(self.get_parameter('nav_action').value).rstrip('/')
        self.auto_cancel = bool(self.get_parameter('auto_cancel').value)
        qos = QoSProfile(depth=10, reliability=ReliabilityPolicy.RELIABLE,
                         history=HistoryPolicy.KEEP_LAST)
        self.pub = self.create_publisher(Twist, self.cmd_topic, 10)
        self.sub = self.create_subscription(ChassisInfoFb, self.chassis_topic, self.on_chassis, qos)
        self.cancel_cli = None
        self.zero = Twist()
        self.state = 'NORMAL'
        self.trigger_time = 0.0
        self.reset_requested = False
        self.trigger_count = 0
        self.create_timer(1.0 / self.rate, self.tick)
        threading.Thread(target=self.console_loop, daemon=True).start()
        self.get_logger().info(f'防跌落守护已启动：{self.cmd_topic} 零速 {self.rate:.0f} Hz，'
                               f'导航 action {self.nav_action}')
    def now_s(self):
        return self.get_clock().now().nanoseconds / 1e9
    def on_chassis(self, msg):
        if self.state != 'NORMAL':
            return
        active = [name for name, field in DROP if getattr(msg.io_fb, field)]
        if active:
            self.trigger(active, msg)
    def trigger(self, active, msg):
        self.state = 'TRIGGERED'
        self.trigger_time = self.now_s()
        self.trigger_count += 1
        print(RED + f'[跌落触发] {"、".join(active)}，立即停车并取消导航' + RST, flush=True)
        self.get_logger().error(f'跌落触发：{"、".join(active)}，电压 '
                                f'{msg.bms_fb.bms_fb_voltage:.2f} V，SOC {msg.bms_flag_fb.bms_flag_fb_soc}%')
        self.publish_zero()
        self.cancel_navigation()
    def cancel_navigation(self):
        if not self.auto_cancel:
            return
        topic = self.nav_action + '/_action/cancel_goal'
        if self.cancel_cli is None:
            self.cancel_cli = self.create_client(CancelGoal, topic)
        if not self.cancel_cli.wait_for_service(timeout_sec=1.0):
            self.get_logger().warn(f'{topic} 不可用（导航未启动？），本次仅执行零速')
            return
        req = CancelGoal.Request()
        req.goal_info = GoalInfo()      # goal_id 全零 = 取消该 action 的全部目标
        future = self.cancel_cli.call_async(req)
        future.add_done_callback(self.on_cancel_done)
    def on_cancel_done(self, future):
        try:
            code = future.result().return_code
        except Exception as exc:
            self.get_logger().warn(f'取消导航调用失败：{exc}')
            return
        self.get_logger().info(f'取消导航 return_code={code}（0 = 已受理）')
    def publish_zero(self):
        self.pub.publish(self.zero)
    def tick(self):
        now = self.now_s()
        if self.state == 'NORMAL':
            return
        self.publish_zero()
        if self.state == 'TRIGGERED' and now - self.trigger_time >= self.hold:
            self.state = 'LOCKED'
            print(RED + f'[已锁定] 零速保持 {self.hold:.1f} s；排除隐患后按 Enter 复位' + RST, flush=True)
            self.get_logger().error('进入锁定态，等待人工确认')
        elif self.state == 'LOCKED' and self.reset_requested:
            self.reset_requested = False
            self.state = 'NORMAL'
            print(GRN + '[已复位] 恢复监听，车辆仍静止' + RST, flush=True)
            self.get_logger().warn('人工确认复位，恢复 NORMAL')
    def console_loop(self):
        while rclpy.ok():
            try:
                line = input()
            except EOFError:
                return
            if line.strip() == '' and self.state == 'LOCKED':
                self.reset_requested = True
    def shutdown(self):
        for _ in range(3):
            self.publish_zero()
            time.sleep(0.05)
        self.get_logger().info(f'守护退出，共触发 {self.trigger_count} 次')

def main(args=None):
    rclpy.init(args=args)
    node = DropGuard()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.shutdown()
        node.destroy_node()
        if rclpy.ok():
            rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## 6. 关键代码与配置

| 代码段 | 作用 | 关键点 |
|---|---|---|
| `DROP` 表 | 6 路开关中文名 ↔ 字段名 | 字段名来自 `IoFb.msg`，true = 跌落 |
| 参数与发布器 | 零速话题、频率、action 名、是否自动取消 | `/cmd_vel` 与 `velocity_smoother` 输出同一话题，避免指令抢占 |
| `on_chassis` | 边沿检测：仅 NORMAL 态检查，触发后不再重复触发 | 已锁定时不重复刷屏 |
| `trigger` | 立即发布零速 + 取消导航 + 打印上下文 | 先停车再取消，保证最短停车时延 |
| `cancel_navigation` | `create_client(CancelGoal, '<action>/_action/cancel_goal')` | 该服务由 action 自动生成；`goal_id` 全零表示取消全部目标 |
| `tick`（20 Hz） | 非 NORMAL 态持续发零速；5 s 后转 LOCKED | 抵消上游残余指令，保证 `/cmd_vel` 连续为零 |
| `console_loop` | 独立线程读 `input()`，仅 LOCKED 时接受回车 | 复位必须人工，且需先排除跌落隐患 |
| `shutdown` | 退出前补发 3 次零速 | 防止退出瞬间残留上一帧速度 |

| 话题/接口 | 类型 | 方向 | 说明 |
|---|---|---|---|
| `/chassis_info_fb` | `yhs_can_interfaces/msg/ChassisInfoFb` | 订阅 | RELIABLE，depth 1（发布端） |
| `/cmd_vel` | `geometry_msgs/msg/Twist` | 发布 | depth 10，20 Hz 零速 |
| `/navigate_to_pose` | `nav2_msgs/action/NavigateToPose` | 取消 | 取消服务 `/_action/cancel_goal`，`action_msgs/srv/CancelGoal` |

| 参数 | 默认 | 说明 |
|---|---|---|
| `hold_seconds` | 5.0 | 零速保持秒数 |
| `publish_rate` | 20.0 | 零速发布频率（Hz） |
| `nav_action` | `/navigate_to_pose` | 导航 action 名，用于推导取消服务 |
| `auto_cancel` | `true` | 关闭后只停车不取消（仅调试用） |

## 10. 回滚与常见问题

回滚：①`Ctrl+C` 退出，脚本补发 3 次零速；②若处于 LOCKED，先排除跌落隐患再按 Enter 或直接退出；③`rm -rf ~/yhs_labs/S2-03`；④确认 `git status` 无新增；⑤本实验不改 Nav2 参数与行为树，无需还原配置。

| 现象 | 原因 | 处理 |
|---|---|---|
| `wait_for_service` 超时、`_action/cancel_goal 不可用` | 导航未启动或 action 名不同 | `ros2 action list -t` 确认；用 `-p nav_action:=<实际名>` |
| 触发后车仍在动 | 上游（`velocity_smoother`）仍在发速度，取消未生效 | 确认 `return_code=0`；必要时按硬件急停；查 `/cmd_vel` 的多发布者 |
| 一直不触发 | 订阅未连上或字段名不符 | `ros2 topic echo /chassis_info_fb --field io_fb --once` 对照 6 个字段 |
| 复位后立刻又锁定 | 跌落信号仍为 true | 先排除隐患；这是设计上的防误复位行为 |
| `ModuleNotFoundError: No module named 'action_msgs'` | 未 source ROS 2 | `source /opt/ros/humble/setup.bash` |
| `No module named 'yhs_can_interfaces'` | 未 source 工作空间 | `source install/setup.bash`；`ros2 pkg prefix` 验证 |
| QoS 不匹配、收不到反馈 | 订阅端被改成 BEST_EFFORT 之外的不兼容策略 | 保持 `RELIABLE` + `KEEP_LAST(10)` |
