# S1-11 多库区地图快速切换

> 场景：一台车服务 2~3 个库区（同一地面层）。核心动作：用 `yhs_nav2.launch.py` 的 `map:=` 直接指向 `src/yhs_nav2/map/*.yaml`，做到"一行命令换地图、改错不编译"。
> 全部命令在**实车工控机 Ubuntu 22.04** 上执行。

```bash
# 每个新终端开头都执行（下文不再重复）
export WS="$HOME/ros2_ws"
source /opt/ros/humble/setup.bash
source "$WS/install/setup.bash"
export MAPDIR="$WS/src/yhs_nav2/map"
```

## 2. 实验目标

1. 列出 `src/yhs_nav2/map/` 下**可用**地图（8 套 `.yaml` + 同名 `.pgm`），并指出 `zgq-g.yaml` 因引用缺失的 `zgq.pgm` 不可用。
2. 用 `map:=` 在 3 个场地间切换，不改源码、不重编译；单次切换（重启栈 + 重新定位）≤ 3 min。
3. 用 `ros2 param get /map_server yaml_filename`、`ros2 lifecycle get /map_server`、`ros2 topic info /map -v` 三项证据确认"加载的正是目标地图且只有一份地图话题"。
4. 地图路径写错时能在启动前拦截（`test -f` 预检），而不是等 `map_server` 报错。
5. 连续 10 次切换成功 100%、无节点崩溃，每次切换后重新确认初始位姿。

## 5. 实施步骤

## 6. 关键配置与代码

### 6.1 启动参数链路（默认不改代码）

`src/yhs_nav2/launch/yhs_nav2.launch.py` 已具备完整 `map` 参数链路：

```python
    map_yaml_file = LaunchConfiguration('map')
    param_substitutions = {'use_sim_time': use_sim_time,
                           'yaml_filename': map_yaml_file}
    configured_params = RewrittenYaml(
        source_file=params_file, root_key=namespace,
        param_rewrites=param_substitutions, convert_types=True)

    declare_map_yaml_cmd = DeclareLaunchArgument(
        'map',
        default_value=os.path.join(bringup_dir, 'map', 'ecarroom.yaml'),
        description='地图名称')
```

含义：`map:=` 经 `RewrittenYaml` 覆盖到 `map_server.yaml_filename`，因此**不需要**改 `param/yhs_nav2.yaml`（该文件的 `yaml_filename: "map.yaml"` 只是占位值）。

### 6.2 可选改动：默认地图改为常用场地

| 位置 | 参数 | 原值 | 新值 | 含义 |
|---|---|---|---|---|
| `yhs_nav2.launch.py` 第 74 行 | `DeclareLaunchArgument('map', default_value=...)` 末段 | `'ecarroom.yaml'` | `'110.yaml'` | 不带 `map:=` 启动时的默认地图 |

修改方式：把该 `DeclareLaunchArgument` 中 `default_value=os.path.join(bringup_dir, 'map', 'ecarroom.yaml')` 的末段改成 `'110.yaml'`，其余不动。

两点注意：① `bringup_dir` 是 `install/` 下 share 目录，写 `110.yaml` 必须保证该地图已随包安装；② 改默认值需要重编 `yhs_nav2`，而 `map:=` 不用——现场交付推荐**只用 `map:=`**。

### 6.3 路径写法要求

- 必须给**绝对路径** `map:="$MAPDIR/110.yaml"`；相对路径按进程 cwd 解析，换终端后极易失效。
- `map_server` 依据 yaml 所在目录解析 `image:`，因此 yaml/pgm 必须成对（`zgq-g.yaml` 不可用即此原因）。
- 自建地图同样给绝对路径，如 `map:=$HOME/maps/warehouse.yaml`。

## 10. 回滚与常见问题

```bash
# 执行目录：$WS
cd "$WS"
cp ~/yhs_labs/S1-11/backup/yhs_nav2.launch.py.orig src/yhs_nav2/launch/yhs_nav2.launch.py
colcon build --symlink-install --packages-select yhs_nav2
```

预期：默认地图恢复 `ecarroom.yaml`。若全程只用 `map:=`，回滚即用 `map:="$MAPDIR/ecarroom.yaml"` 重启。

| 现象 / 报错 | 原因 | 处理 |
|---|---|---|
| 加载 `zgq-g.yaml` 时报找不到 `zgq.pgm`、地图空白 | 该 yaml 引用的 `zgq.pgm` 缺失（目录内只有孤儿 `zgq-c.pgm`） | 换 8 套可用地图之一；确需该场地则重新建图 |
| `param get /map_server yaml_filename` 返回 `map.yaml` | 未传 `map:=`，用了参数文件占位值 | 启动命令补绝对路径 `map:=` |
| map_server 报打不开地图且路径怪异 | 传了相对路径，按 cwd 解析 | 一律用 `$MAPDIR/xxx.yaml` |
| 加载成功但 RViz 还是旧场地 | 旧栈未退干净或 RViz 订阅旧 `/map` | `ros2 node list` 为空后再启动；`topic info /map -v` 应为 1 |
| `ros2 lifecycle get /amcl` 为 `unconfigured` | 地图加载失败导致 amcl 无法配置 | 先修地图路径；或 `autostart:=true` 重启 |
| 定位收敛但整体偏移 1 m 以上 | 初始位姿沿用了上一个场地的坐标 | 每场地切换后必须重给位姿（`2D Pose Estimate` 或脚本） |
| 改了 launch 默认值不生效 | 只改 `src/` 未编译，或 source 了别的工作空间 | 按第 7 节编译并 grep `install/...`；`echo $AMENT_PREFIX_PATH` 检查 |
