## 0. 前置条件检查

开始之前，请先确认以下条件都已满足。**任何一项不满足都请先解决再往下走。**

### 0.1 你的电脑（学生机）

| 检查项 | 检查方法 | 合格标准 |
|--------|----------|----------|
| 操作系统 | `uname -a` (Mac/Linux) 或 `systeminfo` (Windows) | Ubuntu 20.04/22.04 或 macOS |
| Python 版本 | `python3 --version` | 3.8 以上 |
| SSH 可用 | `ssh -V` | 有输出版本信息 |
| 工作空间目录 | 找到你的 ROS2 工作空间 | 例如 `~/ros2_ws/src/yhs_traffic_sign/` |

### 0.2 ROS 小车

| 检查项 | 检查方法 | 合格标准 |
|--------|----------|----------|
| 电源开启 | 观察底盘指示灯 | 常亮绿色 |
| 遥控器在手 | 确认遥控器能控制小车 | 按方向键小车能动 |
| 车载电脑开机 | 通过 SSH 连接测试 | 能登录 |
| 路由器/交换机 | 所有设备在同一网络 | 能互相 ping 通 |

### 0.3 网络连通测试（重要！）

**在你的电脑上打开终端，依次执行：**

**步骤 0.3.1 — 记录小车 IP 地址**

> 如果老师已经告诉你小车 IP，跳过这一步。

```bash
# 通过路由器后台查看，或者在小车上插显示器看
# 假设小车 IP 是 192.168.1.102（请替换成你实际的）
```

**步骤 0.3.2 — SSH 连接测试**

```bash
ssh qg@192.168.1.102
```

预期结果：
```
qg@192.168.1.102's password:  # 输入密码后回车
qg@dt-mini:~$                   # 成功登录，出现提示符
```

❌ **常见问题：**
- `Connection timed out` → 检查小车电源和网线/WiFi
- `Permission denied` → 用户名/密码错了，问老师
- `Connection refused` → 小车电脑没开机，或者 sshd 没启动

**步骤 0.3.3 — 登录后确认 ROS2 环境**

在小车终端（就是刚才 SSH 进去的那个）里执行：

预期结果：

继续执行：
```bash

```

预期结果：
```

```

记下来这个版本号，后面要用。

**步骤 0.3.4 — 退出小车 SSH**

```bash
exit
```

# 第一环节：代码部署到 ROS 小车

## 🎯 本环节目标

把 `yhs_traffic_sign` 功能包的代码从你的电脑复制到小车上，让小车本地也有一份代码。

## 📋 前置准备

- 你的电脑和小车已经通过 SSH 连通（环节 0.3 已完成）
- 你知道：**小车 IP**、**SSH 用户名**、**ROS2 版本**

---

### 步骤 1.1 — 确认你电脑上的代码位置

**在你电脑的终端执行：**

```bash
# 查看源码根目录下有没有我们的功能包
ls -d ~/ros2_ws/src/yhs_traffic_sign 2>/dev/null \
   || ls -d ~/ros2_ws/src/yhs_traffic_sign 2>/dev/null \
   || find ~ -maxdepth 5 -name "yhs_traffic_sign" -type d 2>/dev/null
```

预期结果：
```
/home/yourname/ros2_ws/src/yhs_traffic_sign   # 显示完整路径
```

> 💡 **记下来这个完整路径**，下面叫它 `YOUR_LOCAL_PACKAGE_DIR`。
> 比如上面输出 `/home/yourname/ros2_ws/src/yhs_traffic_sign`，那就是它。

### 步骤 1.2 — 在小车上准备接收目录

**SSH 登录到小车，执行：**

```bash
ssh qg@192.168.1.102    # 换成你实际的小车IP

# 登录后，创建工作空间目录（如果还没有的话）

ls ~/ros2_ws/src/
```

预期结果：
```

# 如果有，应该能看到其他功能包目录（比如 yhs_can_control、yhs_nav2 等）
```

### 步骤 1.3 — 复制代码到小车（scp 方式）

**从你电脑的另一个终端窗口执行（不要在 SSH 里执行！）：**


输入密码后等待传输完成。代码量很小，应该几秒内完成。

### 步骤 1.5 — 安装 Python 依赖包（ultralytics + OpenCV）

> ⚠️ **注意：** 多数 ROS 小车的工控机**无法访问外网**（DNS 解析失败、公司/实验室网络屏蔽 pypi.org）。
> 下面分两种情况，请按你的实际情况选择。

**先测一下小车有没有外网（SSH 到小车执行）：**
```bash
ping -c 2 pypi.org
```

如果输出 `2 packets transmitted, 0 received` → **无外网**，走**方案 B**。
如果收到回复 → **有外网**，走**方案 A**。

---

#### 方案 A：小车有外网（简单）

**SSH 登录小车，执行：**

```bash
# 安装 ultralytics（YOLOv8 官方库）
pip3 install ultralytics opencv-python-headless numpy

# 验证安装
python3 -c "from ultralytics import YOLO; print('✅ ultralytics OK')"
python3 -c "import cv2; print('✅ cv2 OK')"
```

如果提示 `pip3` 找不到：先 `sudo apt install python3-pip`。
如果网络慢超时：配置清华镜像 `pip3 config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`

---

#### 方案 B：小车无外网（推荐用）⭐

完整离线安装流程请参考同目录下的 **[离线安装指南-Python依赖.md](file:///Users/waiyu/Library/Mobile%20Documents/com~apple~CloudDocs/Work/Personal/ROS2%20on%20YHS%20DT-mini%20Tutorial/src/yhs_traffic_sign/%E7%A6%BB%E7%BA%BF%E5%AE%89%E8%A3%85%E6%8C%87%E5%8D%97-Python%E4%BE%9D%E8%B5%96.md)**。下面给核心步骤速查：

##### B-1 在 Windows（有网）下载离线包

打开 Windows cmd（`Win + R` → `cmd`），执行：

```cmd
REM 创建下载目录
mkdir D:\offline_pip
cd D:\offline_pip

REM 下载 ultralytics + 全部依赖（关键：匹配小车 Python 3.10 + Linux x86_64）
pip3 download ultralytics opencv-python-headless numpy torch torchvision torchaudio ^
  -d D:\offline_pip ^
  --python-version 3.10 ^
  --platform manylinux2014_x86_64 ^
  --only-binary=:all:
```

等待下载完成（torch 比较大 ~200MB，耐心等）。预期目录里有 **40-60 个 .whl 文件**。

##### B-2 MobaXterm SFTP 上传到小车

1. MobaXterm SSH 连上小车
2. 左侧文件树创建 `~/offline_pip/` 目录
3. Windows 资源管理器打开 `D:\offline_pip\`
4. **全选所有 .whl → 拖到 MobaXterm 左侧 `~/offline_pip/`**
5. 等上传进度条消失即可

##### B-3 小车本地离线安装

回到 MobaXterm 终端（SSH 会话），执行：

```bash
# 验证上传完整
ls ~/offline_pip/*.whl | wc -l

# 离线安装（核心命令：--no-index 禁止联网，--find-links 指定本地目录）
cd ~/offline_pip
pip3 install --no-index --find-links=. \
  ultralytics opencv-python-headless numpy
```

##### B-4 验证安装

```bash
python3 -c "from ultralytics import YOLO; print('✅ ultralytics OK')"
python3 -c "import cv2; print('✅ cv2 OK')"
python3 -c "import numpy as np; print('✅ numpy OK')"
```

三条都输出 ✅ → 安装成功！🎉

# 第二环节：工作空间编译

## 🎯 本环节目标

把刚复制到小车的源代码编译成可执行的 ROS2 节点。

## 📋 前置准备

- 第一环节所有步骤已完成
- 小车 SSH 连接正常
- Python 依赖已安装

---

### 步骤 2.1 — 加载 ROS2 环境

**SSH 登录小车，** 每次开新终端都要先执行这两句！

```bash
# 加载系统 ROS2
source /opt/ros/humble/setup.bash
#                                              ^^^^^^^^
#                           换成你在步骤 0.3.3 看到的版本 (foxy / humble / iron)
```

> 💡 **快捷方式：** 加到 bashrc 里，以后自动加载
> ```bash
> echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
> echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
> source ~/.bashrc
> ```

### 步骤 2.2 — 进入工作空间

```bash
cd ~/ros2_ws
pwd
```

预期结果：
```
~/ros2_ws
```

### 步骤 2.3 — 编译（Colcon 方式）

```bash
colcon build --packages-select yhs_traffic_sign
```

> 💡 **什么是 colcon？** 它是 ROS2 的官方编译工具，替代 ROS1 的 catkin_make。
> `--packages-select` 表示只编译这个包，跳过其他包节省时间。

**等待编译完成...** 编译 Python 包很快，通常 10 秒内结束。

预期结果（成功）：
```
Starting >>> yhs_traffic_sign
Finished <<< yhs_traffic_sign [1.03s]

Summary: 1 package finished [1.03s]
```

❌ **常见问题与解决：**

| 报错信息 | 原因 | 解决命令 |
|----------|------|----------|
| `colcon: command not found` | 没装 colcon | `sudo apt install python3-colcon-common-extensions` |
| `PackageNotFoundError: yhs_can_interfaces` | 缺少依赖包 | 需要把 yhs_can_interfaces 也复制到 src/ 并先编译 |
| `No module named 'ultralytics'` | Python 包没装 / **小车无外网** | 有网：`pip3 install ultralytics`；无网：见步骤 1.5 方案 B 离线安装法 |
| 警告 `ament_python` 相关 | package.xml 依赖缺失 | `sudo apt install ros-$ROS_DISTRO-ament-python` |

### 步骤 2.4 — 编译完整项目（包含底盘控制）

如果要同时编译底盘控制包：

```bash
# 先把接口包也编译了
colcon build --packages-select yhs_can_interfaces yhs_can_control yhs_traffic_sign

# 或者一次编译 src/ 下所有包（首次推荐）
colcon build
```

### 步骤 2.5 — 加载新编译的环境

```bash

```

# 第三环节：小车数据采集

## 🎯 本环节目标

让小车在真实场景中行驶，用相机拍摄交通标识牌图片，**为模型训练准备数据集**。

## 📋 前置准备

- 第一、二环节全部完成
- 小车能被遥控器手动控制
- 道路上/仓库里有真实的交通标识牌可拍摄

## ⚠️ 安全警告（必读！）

1. **采集前拔下小车 CAN 总线的电机驱动插头**（或告诉老师，让小车处于"空挡"不会真的跑）
2. **必须有人拿着遥控器随时待命**，紧急情况立刻停车
3. 拍摄时人不要站在小车正前方
4. 采集完数据立即停车，不要长时间无意义行驶

---

### 步骤 3.1 — 启动相机驱动

**SSH 登录小车，打开第 1 个终端：**

```bash
source ~/ros2_ws/install/setup.bash

# 启动 Orbbec 相机（如果你的小车用的是 Orbbec）
ros2 launch orbbec_camera gemini.launch.py
# 如果 Astra / Astra Pro / Femto 等，launch 文件名可能不同，参考硬件文档
```

预期结果：
```

...
[INFO] [orbbec_camera_node-1]: Image topics ready: /camera/color/image_raw
```

**打开第 2 个终端，验证相机画面：**

```bash
source ~/ros2_ws/install/setup.bash

# 列出当前活跃的话题，看有没有 color/image_raw 和 depth
ros2 topic list | grep camera
```

预期结果：
```

/camera/depth/image_raw
```

### 步骤 3.2 — 启动 RViz（可选，看实时画面）

**在你的电脑上（不是小车）：**

```bash

# RViz 里点击 Add → Image → 选择 /camera/color/image_raw
```

> 💡 如果网络延迟太大，RViz 画面卡顿，直接跳过这步。相机数据已经在 ROS2 里流动了。

### 步骤 3.3 — 启动数据采集节点

**SSH 登录小车，打开第 3 个终端：**

```bash
source ~/ros2_ws/install/setup.bash

# 创建保存目录
mkdir -p ~/ros2_ws/src/yhs_traffic_sign/dataset/images
DATA_DIR=~/ros2_ws/src/yhs_traffic_sign/dataset/images

# 开始录制
ros2 bag record -o ~/ros2_ws/recordings/traffic_sign_$(date +%Y%m%d_%H%M%S) \
  /camera/color/image_raw
```

预期结果：
```
[INFO] [rosbag2_recorder]: Press Ctrl+C to stop recording
[INFO] [rosbag2_recorder]: Recording to: ~/ros2_ws/recordings/traffic_sign_20261119_101530
```

### 步骤 3.4 — 手动操控小车采集数据

**拿起遥控器，开始采集！**

推荐的采集策略：

| 条件 | 建议拍摄数量 |
|------|-------------|
| 每个标识牌在"正前方" | 30-50 张 |
| 每个标识牌带"角度"拍摄 | 左30°、右30°、左60°、右60° 各 20 张 |
| 不同距离（0.5m ~ 5m） | 远、中、近各覆盖 |
| 不同光照（白天/背光/阴影） | 都要覆盖 |

> 💡 **拍照数量小建议：** 三类标识牌 × 每类 200 张 = 总共 **600 张** 起步。
> 越多越好，但至少保证每类不少于 150 张。

**操作规范：**
1. 手持遥控器，慢慢开向交通标识牌
2. 标识牌出现后保持 2-3 秒再移开（保证帧不模糊）
3. 每个标识牌都尝试不同角度和距离
4. 遇到行人/障碍物立刻停车

### 步骤 3.5 — 结束采集

数据采集完成后，**回到录制终端**按：

```
Ctrl + C
```

预期结果：
```
[INFO] [rosbag2_recorder]: Stopping...
[INFO] [rosbag2_recorder]: Recording saved to ~/ros2_ws/recordings/traffic_sign_20261119_101530
```

### 步骤 3.6 — 把 rosbag 转成图片文件

**ROS bag 格式不便标注，需要转成单张图片。SSH 小车执行：**

```bash
source ~/ros2_ws/install/setup.bash

# 安装 bag 转图片工具
pip3 install bagpy --quiet 2>/dev/null || true

# 方法 A：用 Python 脚本（推荐）
python3 - << 'EOF'
import rclpy
from rclpy.serialization import deserialize_message
from rosbag2_py import SequentialReader, StorageOptions, ConverterOptions
from sensor_msgs.msg import Image
import cv2, os

BAG_PATH = "~/ros2_ws/recordings/traffic_sign_20261119_101530"  # 换成你的目录
OUT_DIR = "~/ros2_ws/src/yhs_traffic_sign/dataset/images"
os.makedirs(OUT_DIR, exist_ok=True)

from bagpy import bagreader
b = bagreader(BAG_PATH)
for topic in b.topics:
    if "image_raw" in topic and "color" in topic:
        msg_list = b.reader.read_messages(topics=[topic])
        for i, (topic, msg, t) in enumerate(msg_list):
            cv2.imwrite(f"{OUT_DIR}/frame_{i:06d}.png", 
                cv2.cvtColor(msg.data.reshape(msg.height, msg.width, -1), 
                             cv2.COLOR_RGB2BGR))
        print(f"导出 {i+1} 张图片")
EOF

# 方法 B：如果 bagpy 不行，用 ros2 bag play + 保存节点
ros2 bag play ~/ros2_ws/recordings/traffic_sign_20261119_101530

# 另开终端用 image_view 保存单帧
ros2 run image_view image_saver --ros-args -r image:=/camera/color/image_raw
```

### 步骤 4.4 — 划分训练集/验证集

**在你的电脑上执行：**

```bash
DATASET_ROOT=~/yhs_traffic_dataset
mkdir -p $DATASET_ROOT/{images,labels}/{train,val}

# 统计图片总数
TOTAL=$(ls $DATASET_ROOT/images/*.png 2>/dev/null | wc -l) \
   || TOTAL=$(ls $DATASET_ROOT/images/*.jpg 2>/dev/null | wc -l)

VAL_COUNT=$(( TOTAL * 20 / 100 ))   # 20% 做验证集
echo "总数=$TOTAL  验证集=$VAL_COUNT"

# 随机打乱所有图片，前 80% 进 train，后 20% 进 val
ls $DATASET_ROOT/images/*.{png,jpg,jpeg} 2>/dev/null | shuf > /tmp/all_images.txt

head -n $(( TOTAL - VAL_COUNT )) /tmp/all_images.txt | while read f; do
    mv "$f" $DATASET_ROOT/images/train/
    # 同名 .txt 也一起搬
    base=$(basename "$f" | sed 's/\.[^.]*$//')
    txt_src=$(dirname "$f")/$base.txt
    [ -f "$txt_src" ] && mv "$txt_src" $DATASET_ROOT/labels/train/
done

tail -n $VAL_COUNT /tmp/all_images.txt | while read f; do
    mv "$f" $DATASET_ROOT/images/val/
    base=$(basename "$f" | sed 's/\.[^.]*$//')
    txt_src=$(dirname "$f")/$base.txt
    [ -f "$txt_src" ] && mv "$txt_src" $DATASET_ROOT/labels/val/
done

# 验证
echo "训练集图片: $(ls $DATASET_ROOT/images/train/ | wc -l)"
echo "验证集图片: $(ls $DATASET_ROOT/images/val/ | wc -l)"
echo "训练集标签: $(ls $DATASET_ROOT/labels/train/ | wc -l)"
echo "验证集标签: $(ls $DATASET_ROOT/labels/val/ | wc -l)"
```

### 步骤 4.5 — 创建训练数据集配置文件

```bash
cat > $DATASET_ROOT/dataset.yaml << 'EOF'
# 交通标识牌检测数据集配置
name: traffic_sign_dataset
train: images/train
val: images/val

# 类别数量（和我们标注的类数一致）
nc: 3

# 类别名称（顺序要和 LabelImg 里的顺序严格一致！）
names:
  0: left_turn
  1: straight
  2: right_turn
EOF

cat $DATASET_ROOT/dataset.yaml
```

### 步骤 4.6 — 开始训练！

```bash
cd $DATASET_ROOT

# 安装 ultralytics（如果还没装）
pip3 install ultralytics --quiet

# 方式 A：用命令行
export PATH="$HOME/Library/Python/3.9/bin:$PATH"   # macOS 需要
yolo detect train \
  data=$DATASET_ROOT/dataset.yaml \
  model=yolov8n.pt \
  imgsz=640 \
  batch=16 \
  epochs=100 \
  device=0 \
  project=runs/traffic_sign \
  name=exp1

# 方式 B：CPU 训练（没有 GPU 时，慢但能用）
yolo detect train \
  data=$DATASET_ROOT/dataset.yaml \
  model=yolov8n.pt \
  imgsz=640 \
  batch=8 \
  epochs=50 \
  device=cpu \
  project=runs/traffic_sign \
  name=cpu_run
```

**参数说明表：**

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| `model=yolov8n.pt` | 使用官方 nano 权重做迁移学习 | n / s / m 可试，n 最快 |
| `imgsz=640` | 输入图像尺寸 | 640 通用；标识牌小可用 1280 |
| `batch=16` | 每次并行训练几张卡 | 显存够就调大，OOM 就调小 |
| `epochs=100` | 总共训练几轮 | 50~150，看收敛情况 |
| `device=0` | 使用 GPU 编号 | 有 GPU 用 `0`，没用用 `cpu` |

训练过程中你会看到：

```
Epoch    GPU_mem   box_loss   cls_loss   dfl_loss  Instances       Size
 1/100      2.1G     1.089      3.475     1.199        128        640: 100%|████| 50/50 [00:45<00:00,  1.09it/s]
```

| 指标 | 合格标准 |

- 只有 `"sign_type":"none"` → 模型文件没放对位置/没加载成功/没识别到

# 附录 A：常见问题排查手册

## A.1 编译阶段

| 报错 | 原因 | 解决 |
|------|------|------|
| `No such file or directory: rclpy` | ROS2 环境没 source | `source /opt/ros/$ROS_DISTRO/setup.bash && source ~/ros2_ws/install/setup.bash` |
| `PackageNotFoundError: yhs_can_interfaces` | 接口包没编译 | 把 `yhs_can_interfaces` 也放 `src/` 并 `colcon build` |
| `ModuleNotFoundError: ultralytics` | Python 包没装 / **小车无外网** | 有网：`pip3 install ultralytics`；无网：见步骤 1.5 方案 B 的离线安装法 |
| `ModuleNotFoundError: cv2` | OpenCV 没装 / **小车无外网** | 有网：`pip3 install opencv-python-headless`；无网：同上，随 ultralytics 一起离线装 |
| `ament_python package.xml missing` | package.xml 格式错 | 参考我们的 `yhs_traffic_sign/package.xml` |

## A.2 运行阶段

| 报错 | 原因 | 解决 |
|------|------|------|
| `[WARN] 模型文件不存在` | 模型路径不对 | 检查 `models/traffic_sign_yolov8n.pt` 是否真的存在 |
| `[INFO] 模拟模式` | 没检测到真实相机 | 相机驱动没启动，先启动 |
| 只有 `"sign_type":"none"` | 相机没输出图/模型不对 | `ros2 topic echo /camera/color/image_raw --once` 看看有没有图 |
| 置信度始终 < 0.5 | 模型没训练好或场景差 | 增加训练数据/调高阈值 |
| 距离读数飘到 999 | 深度图无效 | 检查深度相机话题 `/camera/depth/image_raw` |
| 控制指令发送了但车不动 | CAN 没连上 | 检查底盘控制节点 `yhs_can_control` 状态 |
| `ros2 topic list` 空的 | ROS2 环境没 source | 重新 `source ~/ros2_ws/install/setup.bash` |

## A.3 训练阶段

| 报错 | 原因 | 解决 |
|------|------|------|
| `CUDA out of memory` | 显存不够 | 减小 `batch=8` 或用 `imgsz=320` |
| `nan` loss | 数据/标签格式错 | 检查 `.txt` 标签每行是不是 5 个数 |
| `Validation mAP=0` | 标签类别和 yaml 不匹配 | `names:` 里 id 要和标注文件 class_id 对应 |
| `ultralytics not found` | 没装库 | 训练用电脑通常有网：`pip3 install ultralytics`；小车离线参考 [离线安装指南-Python依赖.md](file:///Users/waiyu/Library/Mobile%20Documents/com~apple~CloudDocs/Work/Personal/ROS2%20on%20YHS%20DT-mini%20Tutorial/src/yhs_traffic_sign/%E7%A6%BB%E7%BA%BF%E5%AE%89%E8%A3%85%E6%8C%87%E5%8D%97-Python%E4%BE%9D%E8%B5%96.md) |
| `bash: yolo: command not found` | ultralytics CLI 没在 PATH | `export PATH="$HOME/Library/Python/3.9/bin:$PATH"` 或用 `python3 -m ultralytics` |
