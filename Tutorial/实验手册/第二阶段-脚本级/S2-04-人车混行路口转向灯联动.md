## 2. 实验目标

1. 能说明 `IoCmd` 中 `io_cmd_lamp_ctrl`、`io_cmd_turn_lamp`（0 关/1 左/2 右）、`io_cmd_braking_lamp` 的语义与驱动换算关系。
2. 能订阅 `/cmd_vel` 的 `angular.z`，超过阈值立即点亮对应转向灯并保持 0.5 s。
3. 能识别相邻速度指令的降速量，点亮刹车灯并保持 1 s。
4. 能实现停车 2 s 后全灯复位（"到点熄灯"），并在脚本退出时把灯光全部复位。
5. 能实测转向灯提前量 ≥ 0.5 s、刹车灯与减速同步误差 ≤ 0.2 s，连续 4 h 灯态无卡死。

## 5. 实施步骤

### 5.1 写入完整脚本

把下面全文写入 `~/yhs_labs/S2-04/turn_signal.py`：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""S2-04 路口转向灯联动：订阅 /cmd_vel，按角速度与减速度驱动 /io_cmd 灯光。"""

import time

import rclpy
from rclpy.node import Node
from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy
from geometry_msgs.msg import PoseWithCovarianceStamped, Twist
from yhs_can_interfaces.msg import IoCmd

TURN_TEXT = {0: '关闭', 1: '左转', 2: '右转'}


class TurnSignal(Node):
    """角速度 → 转向灯；减速 → 刹车灯；停车 → 全灭。"""

    def __init__(self):
        super().__init__('turn_signal_s2_04')
        params = (('angular_threshold', 0.1), ('turn_hold', 0.5), ('brake_decel', 0.03),
                  ('brake_hold', 1.0), ('stop_hold', 2.0), ('publish_rate', 10.0),
                  ('cmd_topic', '/cmd_vel'), ('io_topic', '/io_cmd'), ('pose_topic', '/amcl_pose'))
        for name, value in params:
            self.declare_parameter(name, value)
        self.thr = float(self.get_parameter('angular_threshold').value)
        self.hold = float(self.get_parameter('turn_hold').value)
        self.decel = float(self.get_parameter('brake_decel').value)
        self.brake_hold = float(self.get_parameter('brake_hold').value)
        self.stop_hold = float(self.get_parameter('stop_hold').value)
        rate = float(self.get_parameter('publish_rate').value)
        cmd_topic = str(self.get_parameter('cmd_topic').value)
        io_topic = str(self.get_parameter('io_topic').value)
        pose_topic = str(self.get_parameter('pose_topic').value)
        qos = QoSProfile(depth=1, reliability=ReliabilityPolicy.RELIABLE,
                         history=HistoryPolicy.KEEP_LAST)
        self.pub = self.create_publisher(IoCmd, io_topic, 10)
        self.cmd_sub = self.create_subscription(Twist, cmd_topic, self.on_cmd, qos)
        self.pose_sub = self.create_subscription(
            PoseWithCovarianceStamped, pose_topic, self.on_pose, qos)
        self.turn = 0
        self.turn_time = 0.0
        self.brake_until = 0.0
        self.stopped_since = None
        self.last_v = None
        self.pose = None
        self.frames = 0
        self.create_timer(1.0 / rate, self.publish_io)
        self.get_logger().info(f'转向灯联动已启动：|w| > {self.thr:.2f} rad/s 亮转向灯，'
                               f'单步降速 ≥ {self.decel:.2f} m/s 亮刹车灯')
    def now_s(self):
        return self.get_clock().now().nanoseconds / 1e9
    def on_pose(self, msg):
        self.pose = msg.pose.pose.position
    def on_cmd(self, msg):
        now = self.now_s()
        v, w = msg.linear.x, msg.angular.z
        self.frames += 1
        if w > self.thr:
            self.set_turn(1, now)
        elif w < -self.thr:
            self.set_turn(2, now)
        elif self.turn != 0 and now - self.turn_time > self.hold:
            self.set_turn(0, now)
        if self.last_v is not None:
            if self.last_v - v >= self.decel and self.last_v > 0.02:
                self.brake_until = now + self.brake_hold
            elif abs(v) < 0.01 and self.last_v > 0.05:
                self.brake_until = now + self.brake_hold
        self.last_v = v
        if abs(v) < 0.02 and abs(w) < 0.02:
            if self.stopped_since is None:
                self.stopped_since = now
            elif now - self.stopped_since >= self.stop_hold:
                if self.turn != 0 or now < self.brake_until:
                    self.set_turn(0, now)
                    self.brake_until = 0.0
                    self.get_logger().info(f'停车 {self.stop_hold:.1f} s，全灯复位（到点熄灯）')
        else:
            self.stopped_since = None
    def set_turn(self, value, now):
        if value == self.turn:
            if value != 0:
                self.turn_time = now
            return
        self.turn = value
        self.turn_time = now
        extra = ''
        if self.pose is not None:
            extra = f'，位姿 ({self.pose.x:.2f}, {self.pose.y:.2f})'
        self.get_logger().info(f'转向灯 → {TURN_TEXT[value]}{extra}')
    def publish_io(self):
        msg = IoCmd()
        msg.io_cmd_lamp_ctrl = True        # 灯光控制使能位，必须为 true
        msg.io_cmd_turn_lamp = self.turn   # 0 关 / 1 左 / 2 右
        msg.io_cmd_braking_lamp = self.now_s() < self.brake_until
        self.pub.publish(msg)
    def shutdown(self):
        msg = IoCmd()
        msg.io_cmd_lamp_ctrl = True
        for _ in range(5):
            self.pub.publish(msg)
            time.sleep(0.1)
        self.get_logger().info(f'灯态已复位（共处理 {self.frames} 帧速度指令）')

def main(args=None):
    rclpy.init(args=args)
    node = TurnSignal()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.shutdown()
        node.destroy_node()
        if rclpy.ok():
            rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### 5.3 指令模拟四类灯效（架空）

```bash
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2}, angular: {z: 0.2}}"
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2}, angular: {z: -0.2}}"
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0}, angular: {z: 0.0}}"
ros2 topic echo /io_cmd --field io_cmd_turn_lamp   # 另开终端
```

预期（腾空状态看灯，或看 `/io_cmd`）：

```text
转向灯 → 左转，位姿 (1.24, -0.36)
转向灯 → 右转，位姿 (1.28, -0.34)
转向灯 → 关闭
```

`io_cmd_turn_lamp` 依次为 `1`、`2`、`0`；第 3 条指令发出后约 2 s，日志出现"全灯复位（到点熄灯）"。刹车灯验证：用 `-p brake_decel:=0.02` 启动，从 0.2 直接发 0.0，`/io_cmd` 的 `io_cmd_braking_lamp` 应为 `true` 约 1 s。

完成标志：左转/右转/关闭/刹车 4 类灯效各出现 1 次，松开 Ctrl+C 后灯全灭。

## 6. 关键代码与配置

| 代码段 | 作用 | 关键点 |
|---|---|---|
| `params` | 角速度阈值、保持时长、刹车阈值、停止复位、话题名 | 阈值均可用 `-p` 现场调整 |
| `on_cmd` | 三件事：转向判定、刹车判定、停止计时 | 只订阅最终 `/cmd_vel`，避免订阅 TEB 中间量 |
| `set_turn` | 去抖：同向命令持续刷新 `turn_time` | 保持 0.5 s，避免过弯中灯闪烁 |
| 刹车逻辑 | 单步降速 ≥ `brake_decel` 或由动到停 → 亮 1 s | 与 `velocity_smoother` 的 20 Hz 输出匹配 |
| 停车复位 | 连续 2 s 速度/角速度近零 → 全灯熄灭 | 即"到点熄灯"，不依赖导航状态 |
| `publish_io`（10 Hz） | 组 `IoCmd`，`lamp_ctrl=True` + 转向 + 刹车 | **`io_cmd_lamp_ctrl` 必须为 true**，否则驱动清除灯控使能位 |
| `shutdown` | 退出前 5 次全灭指令 | 杀脚本后灯不残留 |
| `on_pose` | 仅记录 `/amcl_pose` 到日志 | 不参与灯效判定，缺失也能运行 |

| 话题 | 类型 | 方向 | 说明 |
|---|---|---|---|
| `/cmd_vel` | `geometry_msgs/msg/Twist` | 订阅 | 来自 `velocity_smoother`，depth 1 |
| `/amcl_pose` | `geometry_msgs/msg/PoseWithCovarianceStamped` | 订阅 | 仅日志，depth 1 |
| `/io_cmd` | `yhs_can_interfaces/msg/IoCmd` | 发布 | depth 10，10 Hz |

| `IoCmd` 字段 | 取值 | 驱动行为（`yhs_can_control_node.cpp`） |
|---|---|---|
| `io_cmd_lamp_ctrl` | true/false | data[0] bit0 灯控使能；false 时整车灯光不受本指令控制 |
| `io_cmd_turn_lamp` | 0/1/2 | 0 清 bit2+bit3；1 清 bit2（左）；2 清 bit3（右） |
| `io_cmd_braking_lamp` | true/false | data[1] bit4，true 亮刹车灯 |

## 10. 回滚与常见问题

回滚：①`Ctrl+C`，脚本会连发 5 次全灭指令；②若灯仍亮，重跑脚本按 Ctrl+C，或临时 `ros2 topic pub -r 5 /io_cmd yhs_can_interfaces/msg/IoCmd "{io_cmd_lamp_ctrl: true}"` 复位；③`rm -rf ~/yhs_labs/S2-04`；④`git status` 应无新增；⑤未修改任何参数文件与行为树。

| 现象 | 原因 | 处理 |
|---|---|---|
| 灯不亮但 `/io_cmd` 有数据 | `io_cmd_lamp_ctrl` 未置 true，或灯控电源未开 | 确认代码中 `lamp_ctrl=True`；查灯光保险与线束 |
| 左右灯相反 | 阈值方向或车辆灯线接反 | 用 `angular.z=+0.2` 对照实车；接反由维修处理 |
| 灯常亮不灭 | 其他节点也在发 `/io_cmd`（如 S2-02 脚本） | `ros2 node list` + `rqt_graph` 查发布者；只保留一个灯控节点 |
| 转向灯抖动 | 角速度在阈值附近波动 | 提高 `angular_threshold` 或 `turn_hold` |
| 订阅不到 `/cmd_vel` | 订阅了 TEB 的中间话题，或导航未启动 | `ros2 topic info /cmd_vel -v` 确认发布者为 `velocity_smoother` |
| `No module named 'geometry_msgs'` / `rclpy` | 未 source ROS 2 | `source /opt/ros/humble/setup.bash` |
| `No module named 'yhs_can_interfaces'` | 未 source 工作空间 | `source install/setup.bash` |
